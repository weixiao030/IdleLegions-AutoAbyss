# IdleLegions自动下井 1.0 发布验证

验证日期：2026-11-09。目标：Windows x64 自包含程序，版本 1.0.0。

## 构建与版本

- 使用锁定的 npm 依赖完成 Vite 生产构建，使用 .NET 8 完成 win-x64 自包含单文件发布。
- Windows ProductName 为「IdleLegions自动下井」，ProductVersion 为 1.0.0，FileVersion 为 1.0.0.0。
- 前端、赞赏图片和桥接脚本均嵌入 EXE，无需另行部署网页资源。
- 打包脚本仅收录 EXE、使用及验证文档、许可和校验清单；不包含用户参数、账号信息、游戏资源或运行证据。
- ZIP 打包后逐项核验文件内容及 SHA-256，包内及包外均提供校验清单。

## 策略回归

在隔离数据目录中加载本次构建的生产程序集，运行现有 SelfTest，**57 项独立检查全部通过**。覆盖循环次数、绳索停止、冻结核心及继承、选卡、商店、技能和事件模拟等已有逻辑。

核心策略、桥接和自测源码与 0.4.3 一致。另配置 GitHub Actions：在干净的 Windows 环境构建自包含 EXE，运行其 `--self-test` 并生成发行包。Actions 每次运行结果可在仓库查看。

网页测试使用生产 `Program.Handle` 和真实嵌入资源；游戏目录及本地数据均指向隔离目录。测试未安装桥接或发起游戏操作。

Lighthouse 在本地生产 HTTP 上以无头 Chrome、默认移动节流检查控制页，单次结果：
