# v1.3.8 发布验证

日期：2026-11-10。Windows x64 自包含发行，配套桥接0.3.4。

## 问题与修复

玩家截图显示的是自动流程暂停，游戏和工具仍在运行。末尾“未收到操作回执，已暂停，禁止自动重试”与旧桥接0.3.1的错误文字一致，说明只换EXE仍可能运行旧脚本；仅凭截图不能证明实际网络丢包位置。

- 网页显示游戏内实际桥接版本及EXE自带版本。检测到旧版或无法解析的版本时提示正常关闭游戏、进入连接设置更新桥接，并提供入口。当前或更高版本不误报；没有快照时不冒充已识别旧桥接。
- 未知操作结果使用最多60秒的恢复窗口，按1/2/4/8/12/15秒分阶段核验。已经取得明确状态证据时立即恢复；桥接忙或快照过期时等待，不覆盖原命令。只读或明确未发出的请求仍最多重试两次。
- 桥接先发布操作后的快照，再进行后续状态查询，减少额外网络等待导致的状态同步延迟。lastAction保留独立操作回执，不被local.refresh覆盖；lastBattle记录commandId。
- 最后一战导致深渊run消失时，仍可通过时间更新且深渊、房间、方法及命令ID一致的战斗回执确认操作已完成。胜利和失败均视为战斗已执行，不伪造胜负。旧战斗、其他深渊、命令ID不符或缺少结果均不能解除暂停。
- 仍不明确时显示简洁的暂停提示，保留原始原因及进度。未放开未知结果下的战斗重发或资源消耗重试。

## 更新与回退

1. 从系统托盘退出旧工具，解压整个新版完整包。
2. 正常关闭游戏，在新版“连接设置”点击“安装 / 更新桥接”。
3. 重新启动游戏并登录。识别到桥接0.3.4后更新提示消失，再继续下潜。

仅替换EXE不会更新已安装或已载入的游戏脚本；更新桥接前不需要删除参数、战报或历史记录。仍遇到未知结果暂停时，先在游戏里核对，不反复点击开始。

回退时正常关闭游戏和工具后使用旧EXE；若需恢复旧桥接，可使用安装时保存的配置和脚本备份。不要同时运行两个控制器。
