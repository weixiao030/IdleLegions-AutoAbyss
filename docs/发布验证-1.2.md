## 冻结构筑与圣所

- 首先补可继承普攻冻结；传说冻结＋每五次攻击弹跳最优，已有普通核心仍可优先升级。本层徽章不能替代跨层核心。
- 缺核心时积累寒冷；有核心后补一个可继承开局盾，不主动购买第二张开局盾，也不把临时徽章当继承盾。
- 减速、减速增伤、异常状态增伤与加快弹跳优先；其后冰毒补充，再考虑暗影标记、已有来源时的标记加深、双暴。
- 火系纯状态增伤、电毒弹跳不按家族整体排斥；只降低实际破坏冻结的普攻附魔或消耗状态效果。
- 圣所倒地先复活；明显低血先治疗。全员生命至少 80%、平均至少 90%，且魂力最低至少 50、平均至少 70 时，优先磨利有已装备伤害技能的队员；健康但低魂力先冥想。其他情况继续比较推演。
- 磨利按指定一人每层 +8% 技能伤害建模，随下潜保留，不提升普攻。队员估值结合技能系数、冷却、群攻和下一战预测。

## 魂力不足事件卡住修复

截图中的“深渊回响”是事件选项，不是提高房间难度的 `run.pacto`。客户端 `_llena_presagio` 读取 `op.get("disponible", true)` 并禁用不可用选项；旧工具未过滤此字段，使无法支付 −20 魂力的左侧缔约仍参与评分。

生产入口现先排除 `disponible=false` 与空 ID，再比较可用选项。左侧不可用、右侧 `pasar` 可用时，仅生成“径直前行”。尚未加载事件时正常请求选项；旧响应缺失 disponible 时仍默认可用。全部不可用则明确暂停，不伪造操作或无限重试。

## 应用图标

新增深色井口、青白冰晶和青绿下潜箭头，统一 EXE、系统托盘、浏览器页签。使用现有 Phosphor `Snowflake`、`CaretDown` bold 字形，原始字形路径未改动，完整 MIT 许可在第三方组件说明。未使用游戏美术。

源文件在 `app/Assets/`：SVG、512 像素 PNG、多尺寸 ICO；生成工具是 `tools/generate_icon.cjs`。普通构建直接使用提交的资源，无需额外图片依赖。

ICO 含 16、20、24、32、40、48、64、128、256 像素九档 32 位图。已查看浅色及深色背景的小尺寸预览；通过 Windows PE 资源 API 只读检查发行 EXE 的 RT_GROUP_ICON / RT_ICON，九档图片逐字节等于源 ICO，并用系统关联图标提取成功。托盘从嵌入资源选取系统所需尺寸并复制独立数据，退出时释放图标。

浏览器生产 HTTP 接口现在返回 200 和 `image/x-icon`，取代旧 204；Chromium 成功解码 256 像素图像。若资源管理器缓存旧图标，可将新版解压到新目录，无需重装桥接。

## 验证结果

- Windows 自包含 EXE 构建成功；隔离集成主机 .NET 编译零警告、零错误。Vite 第三方依赖的 `use client` 指令提示不影响构建。
- 发行 EXE 的 **108 项后端自测全部通过**：包含已有策略与 1,680 种合法阵容回归、新构筑、继承核心与盾去重、22 种 char 和 22 种 variant 回退、必经软避让、保存重载、健康/低血/低魂力/倒地圣所、事件可用性过滤、生产事件决策、图标尺寸及嵌入资源一致性。
- 生产前端、生产 HTTP 处理器、独立配置目录的浏览器验证：**41 项策略检查、23 项阵容回归、7 项图标检查全部通过**。测试覆盖全部精英选择与保存重载、非法 ID、键盘、失败重试、运行中禁用以及 1440/1024/768/390 宽度；无未处理 JavaScript 异常。故意非法请求产生的 HTTP 400 属预期测试结果。
- 图标验证后最终 EXE SHA-256：`7af1df71ab56b48b9becf3bb7d053429397786e8c28e290d2d8620812c3a7d40`。发布包另附完整 SHA256SUMS 清单。
- 发布打包采用固定文件白名单，不包含玩家配置、令牌、研究快照、游戏程序、反编译脚本或提取游戏资源。

本地证据位于 `output/strategy-20261109/`，包括 self-test、browser-check-final、formation-regression-final、icon-browser-check、icon-resource-check、client-evidence、web-evidence 及构建日志；截图在 `output/playwright/strategy/`。构建前备份在 `backups/strategy-20261109/`、`backups/formation-20261109/` 和 `backups/icon-20261109/`。
