# IdleLegions自动下井使用说明

版本 1.4.0　更新日期 2026年11月11日

本说明介绍安装连接、四套下潜策略、策略四自定义选牌、运行参数、战绩与维护。首次使用请先阅读同目录的《使用教程.docx》，按步骤安装桥接并确认游戏连接，再开始下潜。

## 适用环境与发行包

适用于 Windows 10 或 Windows 11 的64位系统、Steam版 Idle Legions，账号需要已解锁深渊。程序包含运行环境和中文网页控制台，无需另装 Node.js、Python 或 .NET。实际战斗、奖励与消耗由游戏结算。

完整解压发行包后，双击“IdleLegions自动下井.exe”。不要在ZIP预览窗口内直接运行，也不要同时运行两个版本。网页右上角应显示 v1.4.0。

| 文件或目录 | 用途 |
|---|---|
| IdleLegions自动下井.exe | 主程序和内嵌中文网页控制台 |
| bridge | 与程序同版的桥接脚本副本，正常使用由连接设置安装 |
| 使用说明.docx | 功能、参数和维护参考 |
| 使用教程.docx | 从首次安装到自动下潜的操作步骤 |
| 默认参数.json | 可导入的默认设置，导入前请备份个人参数 |
| 启动说明.txt | 简短启动与升级提示 |
| CHANGELOG.md | 版本更新记录 |
| SHA256SUMS.txt | 包内文件校验值 |
| LICENSE.txt及第三方许可文件 | 软件及运行环境的许可说明 |

软件免费开源，赞赏完全自愿，不影响任何功能。包内不包含游戏本体、账户数据或登录令牌。卡牌图鉴的图片和中文资料内嵌在程序中，不需要玩家另装卡图。

## 首次连接与升级

1. 从系统托盘正常退出旧版工具，正常关闭游戏。
2. 完整解压 v1.4.0 ZIP，运行“IdleLegions自动下井.exe”。浏览器会打开本机控制台；网页关闭后可从托盘重新打开。
3. 在左侧打开“连接设置”。自动识别失败时，在“游戏路径”填写游戏目录中 client.exe 的完整路径，等待自动保存完成。可在 Steam 的本地文件浏览功能中找到安装目录。
4. 游戏保持关闭，点击“安装 / 更新桥接”。程序会备份原配置并添加本工具的自动加载项；不需要手动复制 bridge 文件夹。
5. 点击“启动游戏”，在游戏中正常登录。等待控制台显示“游戏已连接”，再进入“下潜控制”。

工具当前自带桥接版本为0.3.6。桥接版本与工具版本独立，桥接不需要改成1.4.0。旧版或未知版本会显示更新提示；仅替换EXE不会更新已安装或已加载的桥接脚本。

升级会沿用本机保存的参数和历史记录。不要删除数据目录，也不要为了升级重新入场。已开始的深渊可继续；新的职业站位仅在下一次入场时生效。

## 保存参数与职业站位

修改后停止输入约650毫秒会自动保存，页面显示保存状态。没有额外的“保存参数”按钮；启动前会等待参数落盘。保存失败时保留草稿并重试，刷新可恢复待保存内容。运行期间配置只读，需要修改时先暂停并等待当前操作完成。

在“策略参数 → 职业与站位”选择四个不同职业。前两位是前排，后两位是后排；选择已上阵职业会交换位置，也可前移、后移。默认从前到后为狂战士、法师、弓箭手、圣骑士。未拥有的职业可保存为方案，但入场前需要换为已拥有职业。

全部参数的导入会替换相应设置，请先导出备份。“自定义选牌”页的专用导入只修改策略四选牌，不切换策略，不修改站位、模拟次数或其他参数。

## 四套下潜策略

| 策略 | 行为与用途 |
|---|---|
| 策略一 当前默认 | 普攻冻结继承前优先冰系，确认继承后比较弹跳、独立普攻、引爆器与增伤，候选不足时择优兜底 |
| 策略二 1.3.1原版 | 独立保留1.3.1原始选牌、商店、目标组合及模拟器，不读取策略四配置 |
| 策略三 冰系后期 | 冻结继承后补每4/5/6次全体弹跳和每8/10次必暴击，再按指定效果与七系各8张遗物目标选牌 |
| 策略四 自定义优先级 | 保留冰冻前置，确认继承后按系列、细分类和单卡的个人设置选牌 |

在“下潜控制”或“策略参数”选择当前策略。仅编辑“自定义选牌”不会自动切换为策略四。运行中不能切换策略。

## 策略四的冰冻前置与自动过渡

开局优先寒冰，最优先选择普攻冰冻。继承菜单有可继承的普攻冰冻时优先带走；没有时按只读的1.3.1参考评分择优继承其他遗物，正常进入下一层继续寻找，不跳过继承，也不因为缺少冰冻而暂停。

只有下一章到达回执确认普攻冰冻遗物已经继承，才启用自定义规则。本章刚取得的冰冻、临时徽章或普通寒冰遗物不能替代继承确认。前置和过渡阶段不应用尚未启用的自定义拉黑、软避让或目标张数。

确认继承后，自定义规则统一用于遗物、徽章、继承和商店选牌。继承优先未达同种三张上限的遗物；全满而游戏仍允许选择时正常选牌推进，不虚报新增第四张。之前继承的遗物应继续保留，程序会核验实际回执。

策略四的全部自定义只作用于策略四，策略一至三和策略二的1.3.1实现均保持独立。临时徽章仅在本章生效，不计为可继承遗物。

## 策略四自定义选牌

从左侧“自定义选牌”进入。页面显示当前本地版本七系列共151张卡牌，其中88张遗物、63张徽章，含卡图、中文名称和效果描述。资料已按本地游戏中文资源和真实菜单回执核实，后续游戏新增卡以实际回执为准。

先排系列，再排该系列的细分类，最后排同类单卡。数字1最高，2其次，以此类推；单卡数字不能跨系列、跨细分类抢位。默认排序来自冻结的1.3.1规则的静态参考，不等同于动态复刻策略二的全部决策。

系列和细分类可长按左侧手柄约三分之一秒，再拖动到目标位置松开。也可使用上下移按钮，或聚焦手柄后按上下方向键、Home、End；Esc可取消拖动。折叠区默认展开，可自行收起。

| 单卡设置 | 实际作用 |
|---|---|
| 优先级 | 在同系列、同细分类内比较，数字越小越优先 |
| 目标张数 | 达到后转为软避让，0表示不限；遗物、徽章、商店赐福独立计数 |
| 软避让 | 强制菜单没有正常候选时才选择，优先于拉黑候选 |
| 拉黑 | 正常排除；强制菜单全部没有其他候选时最后兜底 |

强制菜单按正常候选、软避让、拉黑末位逐级兜底，偏好不会阻断自动流程。商店不会为了软避让或拉黑兜底而消费，没有合适商品时继续路线。游戏标记不可用的选项不能被兜底变成可用。

“导出选牌”保存策略四专用JSON，包含有效默认值、系列顺序、细分类顺序和单卡设置。“导入选牌”接受本工具导出的专用格式，错误文件会提示原因并保留原配置。运行时可浏览和导出，暂停后才可编辑或导入。

## 运行方式与常用参数

在“下潜控制”依次选择下潜策略和运行方式，再点击“开始下潜”。程序优先继续已有深渊；“仅推演，不执行”只查看建议，不派发游戏动作。

| 运行方式 | 结束条件 |
|---|---|
| 单次下潜 | 一轮到最深通关或战败后结束 |
| 循环指定次数 | 每轮结束后再次入场，遵守次数与保留绳索设置 |
| 循环到绳索用完 | 每轮结束后再次入场，保留0根，直到绳索耗尽 |
| 继续当前计划 | 恢复暂停前的循环安排和累计报告 |

| 参数 | 默认与含义 |
|---|---|
| 每候选模拟次数 | 2000；非正数关闭抽样，改用构筑与路线评分 |
| 操作间隔 | 1000毫秒；非正数不额外等待，已有配置沿用原值 |
| 停止深度及通关层数 | 0为不限；设终点后暂停保留深渊，不执行撤离 |
| 最低胜率及生命暂停线 | 默认0关闭；启用后会按条件暂停 |
| 保留绳索 | 默认2根，次数循环生效；绳索用完模式使用0根 |
| 契约与奖励阶段 | 默认前7层，即P0至P6；两个范围独立设置 |
| 前期护盾避让 | 默认前7层优先不选，无正常候选仍可兜底 |
| 普攻状态 | 默认允许点燃、禁止带电；策略四继承后以专用选牌为准 |

数值不设额外产品范围，但整数仍受32位表示限制，比例与权重必须为有限数字。没有完成输入的负号、小数等保留为草稿，不会偷偷转为0。过大的参数可能导致长时间计算或模型无法产生有效结果。

## 路线与资源操作

前期有普攻冻结时优先寻找战斗以争取核心与碎屑奖励，奖励阶段后优先避战，必经战斗照常进行。奖励层数、缔约层数和后续避战开关相互独立，路线权重不是掉落概率。

自动缔约默认在前7层且持有普攻冻结时生效；默认避开前8次受击免疫和15%闪避契约。跳过签约仍正常打房间，已经签订的效果不会撤销。事件内不可用的缔约选项与提高房间难度的契约是不同操作，程序按游戏实际可用菜单处理。

精英避让是软偏好，默认选中陪葬旗官。必经或更安全的路线仍可前进，不因名单停住。未知预览不会猜测敌人身份。默认跳过战斗播放，使用游戏原有跳过功能，不改变服务端胜负与奖励。

商店比较实际余额、可恢复缺口、商品收益和不购买基线；不为未知收益或未建模诅咒盲目消费。圣所优先复活倒地队员，再按生命、魂力与预计收益比较休息、冥想和磨利；磨利只增强技能，不增强普攻。技能调整默认关闭，保留玩家原技能槽设置。

## 战绩与本地预测

“运行报告”可按轮次和深度查看角色输出、承伤、暴击、技能与反应、卡牌触发、资源差分、装备及已确认取得卡牌。展开角色后可继续展开技能或效果；新记录还可显示战前构筑、实际技能参数和治疗。旧记录缺少字段时不倒填当前装备和倍率。

数值以万、亿显示，悬停可查看精确值，导出保留原数字。资源表每轮每层保留最后一场观察，不把每场余额相加；装备表只显示已确认神话和正数神话邮寄或待领取记录，完整报告仍保留其他原始记录。

本地模拟是近似模型，不是服务端完整公式。冻结时长、敌人强度和纯电清除冻结等设置是模型假设；抽样区间不包含模型误差，不保证真实胜率。未解析效果不会虚构收益。实际结果始终以游戏回执为准。

## 暂停恢复与故障处理

“暂停下潜”会等待已派发操作的回执后停止，避免中途重复消费。网络请求失败或结果未知时，程序先只读重查并分阶段核验；最多约60秒，仍不能确认才暂停。不明状态不要同时手动重复战斗或继承。查看运行日志，确认游戏状态后使用“继续当前计划”。

| 现象 | 处理步骤 |
|---|---|
| 等待游戏连接 | 确认client.exe路径、已安装桥接、游戏已重启且完成登录 |
| 桥接版本过旧或未知 | 正常关闭游戏，在连接设置安装或更新，再启动登录 |
| 网页打不开 | 从系统托盘选择打开控制台；不要收藏含旧端口的临时地址 |
| 参数不能编辑 | 确认当前是否自动下潜；需改配置时先等待暂停完成 |
| 尚未启用自定义排序 | 查看冰冻是否已由下一章回执确认继承，刚取得不等于已继承 |
| 因运行条件停止 | 检查目标次数、绳索、停止深度和生命或胜率暂停线 |
| 没有卡图或版本仍旧 | 退出旧工具，再运行本次解压目录中的1.4.0程序 |

关闭网页不会停止自动流程。系统托盘可打开控制台、暂停或退出；退出工具不会关闭游戏。不要并行运行两个控制器，也不要在程序等待回执时派发同一游戏动作。

## 数据备份与卸载

参数、日志和战斗记录位于 %LOCALAPPDATA%\FrostAbyss。桥接与安装前备份位于 %APPDATA%\Godot\app_userdata\Idle Legions\frost_abyss。分享排查记录前，请自行确认未包含个人信息。

卸载桥接前先停止自动流程、正常关闭游戏，再在“连接设置”点击“卸载桥接”。只移除本工具自己的自动加载项，保留其他插件和配置备份。回退版本时先从托盘退出当前工具，再运行保留的旧版；不要同时运行。

历史更新和技术验证保留在源码仓库，不随完整包重复分发。完整包只保留程序、桥接副本、两份Word文档、默认参数、启动说明、更新记录、校验文件和许可资料。
