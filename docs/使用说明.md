# IdleLegions自动下井使用说明

版本 1.5.2　更新日期 2026年11月12日

本说明介绍安装连接、七套下潜策略、策略四自定义选牌、运行参数、战绩与维护。首次使用请先阅读同目录的《使用教程.docx》，按步骤安装桥接并确认游戏连接，再开始下潜。

## 适用环境与发行包

适用于 Windows 10 或 Windows 11 的64位系统、Steam版 Idle Legions，账号需要已解锁深渊。程序包含运行环境和中文网页控制台，无需另装 Node.js、Python 或 .NET。实际战斗、奖励与消耗由游戏结算。

完整解压发行包后，双击“IdleLegions自动下井.exe”。不要在ZIP预览窗口内直接运行，也不要同时运行两个版本。网页右上角应显示 v1.5.2。

| 文件或目录 | 用途 |
|---|---|
| IdleLegions自动下井.exe | 主程序和内嵌中文网页控制台 |
| bridge | 与程序同版的桥接脚本副本，正常使用由连接设置安装 |
| 使用说明.docx | 功能、参数和维护参考 |
| 使用教程.docx | 从首次安装到自动下潜的操作步骤 |

| 启动说明.txt | 简短启动与升级提示 |
| CHANGELOG.md | 版本更新记录 |
| SHA256SUMS.txt | 包内文件校验值 |
| LICENSE.txt及第三方许可文件 | 软件及运行环境的许可说明 |

软件免费开源，赞赏完全自愿，不影响任何功能。包内不包含游戏本体、账户数据或登录令牌。卡牌图鉴的图片和中文资料内嵌在程序中，不需要玩家另装卡图。


## 首次连接与升级

1. 从系统托盘正常退出旧版工具，正常关闭游戏。
2. 完整解压 v1.5.2 ZIP，运行“IdleLegions自动下井.exe”。浏览器会打开本机控制台；网页关闭后可从托盘重新打开。
3. 在左侧打开“连接设置”。自动识别失败时，在“游戏路径”填写游戏目录中 client.exe 的完整路径，等待自动保存完成。可在 Steam 的本地文件浏览功能中找到安装目录。
4. 游戏保持关闭，点击“安装 / 更新桥接”。程序会备份原配置并添加本工具的自动加载项；不需要手动复制 bridge 文件夹。
5. 点击“启动游戏”，在游戏中正常登录。等待控制台显示“游戏已连接”，再进入“下潜控制”。

工具当前自带桥接版本为0.3.7。桥接版本与工具版本独立，桥接不需要改成1.5.2。旧版或未知版本会显示更新提示；仅替换EXE不会更新已安装或已加载的桥接脚本。

升级会沿用本机保存的参数和历史记录。不要删除数据目录，也不要为了升级重新入场。已开始的深渊可继续；新的职业站位仅在下一次入场时生效。

## 保存参数与职业站位

修改后停止输入约650毫秒会自动保存，页面显示保存状态。没有额外的“保存参数”按钮；启动前会等待参数落盘。保存失败时保留草稿并重试，刷新可恢复待保存内容。运行期间配置只读，需要修改时先暂停并等待当前操作完成。

在“策略参数 → 职业与站位”选择四个不同职业。前两位是前排，后两位是后排；选择已上阵职业会交换位置，也可前移、后移。默认从前到后为狂战士、法师、弓箭手、圣骑士。未拥有的职业可保存为方案，但入场前需要换为已拥有职业。

全部参数的导入会替换相应设置，请先导出备份。“自定义选牌”页的专用导入只修改策略四选牌，不切换策略，不修改站位、模拟次数或其他参数。


## 七套下潜策略

| 策略 | 行为与用途 |
|---|---|
| 策略一 当前默认 | 冰川优先，否则先冰系4张，再七系各4张，全部达标后按新增收益比较 |
| 策略二 经典修正版 | 保留经典模型，修正继承识别和重复冻结偏置，不读取策略四配置 |
| 策略三 冰系后期 | 冰川或冰系4张前置，满系让位，补齐七系各4张后比较单卡收益 |
| 策略四 收益比较或自定义 | 相同冰系和七系4张阶段；可手动排序未满系，全部达标后收益比较 |
| 策略五 | 纯UCT树搜索，不使用系列置顶或神经网络 |
| 策略六 | 实战自校准UCT，自动爬层，极度吃CPU |
| 策略七 | 神经网络加PUCT；模型未通过验证时用UCT |

首页点击“策略说明”可在弹窗逐项查看七套策略的决策规则、优点与局限；查看说明不切换策略。

在“下潜控制”或“策略参数”选择当前策略。仅编辑“自定义选牌”不会自动切换为策略四。运行中不能切换策略。

## 冰川与四张羁绊阶段

七个策略统一优先取得并继承冰川（单卡冻结＋每5次全体弹跳）；没有冰川就凑冰系4张，不额外追普通冻结或非冰弹跳。确认继承冰川或4张冰系遗物后才启用所选策略。随后一、三、四补齐七系各4张，全部达标后按单卡新增收益比较；二恢复经典模型，五至七恢复各自树搜索。

本层获取按当前遗物计数；章末继承只按到达回执中的旧遗物计数。本层达到4张不能冒充已经继承4张。徽章、赐福不占遗物张数；只把真实已出现且符合门槛的徽章投影为可保留效果，不凭空生成冻结徽章。冰锥遗物与2张羁绊冰锥在图鉴中明确区分。

继承同种遗物最多三张，本层获取不使用此上限。没有冰牌的强制菜单择优过渡，下次继续补冰；商店无合适商品时离店。策略二仅在共用前置完成后恢复经典修正版。

策略四“光系只继承普攻狂热”默认关闭。需要时在“自定义选牌”点击“使用此配置”，优先保留狂热（au_fervor）、连祷（au_letania）各一份，再补其他系列。其他光牌仍可在本层凑羁绊，章末优先不继承；仅剩光牌的强制菜单会合法过渡。点击“关闭此配置”可恢复原行为。启用和关闭都不改动已有单卡配置，其他策略不读取此开关。

## 策略四自定义选牌

从左侧“自定义选牌”进入。页面显示当前本地版本七系列共151张卡牌，其中88张遗物、63张徽章，含卡图、中文名称和效果描述。资料已按本地游戏中文资源和真实菜单回执核实，后续游戏新增卡以实际回执为准。

默认选择“收益比较”：遵守4张羁绊阶段，并在同阶段按当前构筑的新增收益跨系列比较。需要手动固定顺序时，切换“系列排序”，再比较系列、细分类、同类单卡；数字1最高，单卡数字不能跨系列抢位。旧专用导出文件无模式字段时按原系列排序导入。

系列和细分类可长按左侧手柄约三分之一秒，再拖动到目标位置松开。也可使用上下移按钮，或聚焦手柄后按上下方向键、Home、End；Esc可取消拖动。折叠区默认展开，可自行收起。

| 单卡设置 | 实际作用 |
|---|---|
| 优先级 | 系列排序模式下，在同系列、同细分类内比较，数字越小越优先 |
| 目标张数 | 达到后转为软避让，0表示不限；遗物、徽章、商店赐福独立计数 |
| 软避让 | 强制菜单没有正常候选时才选择，优先于拉黑候选 |
| 拉黑 | 正常排除；强制菜单全部没有其他候选时最后兜底 |

强制菜单按正常候选、软避让、拉黑末位逐级兜底，偏好不会阻断自动流程。商店不会为了软避让或拉黑兜底而消费，没有合适商品时继续路线。游戏标记不可用的选项不能被兜底变成可用。

“导出选牌”保存策略四专用JSON，包含比较方式、有效默认值、系列顺序、细分类顺序和单卡设置。“导入选牌”接受本工具导出的专用格式，错误文件会提示原因并保留原配置。运行时可浏览和导出，暂停后才可编辑或导入。


## 运行方式与常用参数

在“下潜控制”依次选择下潜策略和运行方式，再点击“开始下潜”。程序优先继续已有深渊；“仅推演，不执行”只查看建议，不派发游戏动作。

| 运行方式 | 结束条件 |
|---|---|
| 单次下潜 | 一轮到最深通关或战败后结束 |
| 循环指定次数 | 每轮结束后再次入场，遵守次数与保留绳索设置 |
| 循环到绳索用完 | 每轮结束后再次入场，保留0根，直到绳索耗尽 |
| 继续当前计划 | 恢复暂停前的循环安排和累计报告 |

| 参数 | 默认与含义 |
|---|---|
| 每候选模拟次数 | 2000；非正数关闭抽样，改用构筑与路线评分 |
| 操作间隔 | 1000毫秒；非正数不额外等待，已有配置沿用原值 |
| 停止深度及通关层数 | 0为不限；设终点后暂停保留深渊，不执行撤离 |
| 最低胜率及生命暂停线 | 默认0关闭；启用后会按条件暂停 |
| 保留绳索 | 默认2根，次数循环生效；绳索用完模式使用0根 |
| 契约与奖励阶段 | 默认前7层，即P0至P6；两个范围独立设置 |
| 前期护盾避让 | 默认前7层优先不选，无正常候选仍可兜底 |
| 普攻状态 | 默认允许点燃、禁止带电；策略四也遵守独立开关 |

常规策略数值不设额外产品范围，搜索和训练参数在界面显示有效范围；整数仍受32位表示限制，比例与权重必须为有限数字。没有完成输入的负号、小数等保留为草稿，不会偷偷转为0。过大的参数可能导致长时间计算或模型无法产生有效结果。


## 路线与资源操作

前期有普攻冻结时优先寻找战斗以争取核心与碎屑奖励，奖励阶段后优先避战，必经战斗照常进行。奖励层数、缔约层数和后续避战开关相互独立，路线权重不是掉落概率。

自动缔约默认在前7层且持有普攻冻结时生效；默认避开前8次受击免疫和15%闪避契约。跳过签约仍正常打房间，已经签订的效果不会撤销。事件内不可用的缔约选项与提高房间难度的契约是不同操作，程序按游戏实际可用菜单处理。

精英避让是软偏好，默认选中陪葬旗官。必经或更安全的路线仍可前进，不因名单停住。未知预览不会猜测敌人身份。默认跳过战斗播放，使用游戏原有跳过功能，不改变服务端胜负与奖励。

商店比较实际余额、可恢复缺口、商品收益和不购买基线；不为未知收益或未建模诅咒盲目消费。圣所优先复活倒地队员，再按生命、魂力与预计收益比较休息、冥想和磨利；磨利只增强技能，不增强普攻。技能调整默认关闭，保留玩家原技能槽设置。

## 战绩与本地预测

“运行报告”可按轮次和深度查看角色输出、承伤、暴击、技能与反应、卡牌触发、每轮资源总获取、装备及已确认取得卡牌。展开角色后可继续展开技能或效果；新记录还可显示战前构筑、实际技能参数和治疗。旧记录缺少字段时不倒填当前装备和倍率。

数值以万、亿显示，悬停可查看精确值，导出保留原数字。资源表每轮结束后只生成一条总获取记录，合计本轮服务端结算收据；核心含到账与邮寄，碎屑按实际结算，缺失收据保留未确认。深度筛选不会拆分整轮总数，奥波币属于井内货币，不计作结算奖励；装备表只显示已确认神话和正数神话邮寄或待领取记录，完整报告仍保留其他原始记录。

本地模拟是近似模型，不是服务端完整公式。冻结时长、敌人强度和纯电清除冻结等设置是模型假设；抽样区间不包含模型误差，不保证真实胜率。未解析效果不会虚构收益。实际结果始终以游戏回执为准。



## 搜索与全部策略实战学习

冰川或冰系4卡确认继承后，策略五用UCT选择、随机前推和回传比较后续行动，不使用手动系列置顶或神经网络。策略六在UCT上结合全部历史战斗和已确认决策的预测残差校准，自动爬层。策略七用112维输入、64单元tanh隐层、策略与价值双头的小型CPU网络辅助PUCT；没有有效模型时自动用UCT。

所有策略均保存已确认实战决策。整次下井结束后，回填最终层数并按设置自动训练。至少需要训练64条且来自4次完整下井、验证16条且来自2次完整下井；按整次下井划分，跨层不拆入两组。新模型的留出验证必须改善且价值误差不退化才会启用，否则保留旧模型。以上只是最低门槛，不保证优于现有策略；旧战报没有完整候选时不会伪造成网络训练行。

独立的“策略 5–7 参数”页可选择 Auto 或手动，显示策略五至七的参数作用。Auto 根据本机逻辑线程数与总内存设置搜索预算、路径步数、并发与训练轮数，显示实际采用值，CUDA保持独立选择。旧配置仍为手动：五1024、六4096、七2048次搜索，路径20步，并发最多默认8。增加预算会增加每次决策等待。每候选模拟次数与树搜索次数是两个参数。暂停会取消本地搜索，已派发动作先完成回执核验。

策略六极度吃CPU，建议16核32线程、32GB内存及SSD。策略七建议8至16核、32GB内存。在“策略 5–7 参数”选择 CPU 或 CUDA，默认 CPU，自动保存，下次训练生效。CUDA需要NVIDIA驱动，无需CUDA Toolkit；只用于网络训练，搜索、模拟和选牌推理仍用CPU。少量样本不保证提速；设备或显存失败会显示原因并从初始权重回退CPU。硬件建议不是最低配置或耗时保证。

未知地图和菜单按历史样本近似；遇到未完整建模的事件或契约后果会截止该条前推。预测可能与游戏差异很大，详细误差与限制见同包《深井搜索与学习-1.5.2.md》。


## 暂停恢复与故障处理

“暂停下潜”会等待已派发操作的回执后停止，避免中途重复消费。网络请求失败或结果未知时，程序先只读重查并分阶段核验；最多约60秒，仍不能确认才暂停。不明状态不要同时手动重复战斗或继承。查看运行日志，确认游戏状态后使用“继续当前计划”。

| 现象 | 处理步骤 |
|---|---|
| 等待游戏连接 | 确认client.exe路径、已安装桥接、游戏已重启且完成登录 |
| 桥接版本过旧或未知 | 正常关闭游戏，在连接设置安装或更新，再启动登录 |
| 网页打不开 | 从系统托盘选择打开控制台；不要收藏含旧端口的临时地址 |
| 参数不能编辑 | 确认当前是否自动下潜；需改配置时先等待暂停完成 |
| 尚未启用自定义排序 | 查看冰川或冰系4张是否已确认继承；本层取得不等于已继承 |
| 因运行条件停止 | 检查目标次数、绳索、停止深度和生命或胜率暂停线 |
| 没有卡图或版本仍旧 | 退出旧工具，再运行本次解压目录中的1.5.2程序 |

关闭网页不会停止自动流程。系统托盘可打开控制台、暂停或退出；退出工具不会关闭游戏。不要并行运行两个控制器，也不要在程序等待回执时派发同一游戏动作。

## 数据备份与卸载

参数、日志和战斗记录位于 %LOCALAPPDATA%\FrostAbyss。桥接与安装前备份位于 %APPDATA%\Godot\app_userdata\Idle Legions\frost_abyss。分享排查记录前，请自行确认未包含个人信息。

卸载桥接前先停止自动流程、正常关闭游戏，再在“连接设置”点击“卸载桥接”。只移除本工具自己的自动加载项，保留其他插件和配置备份。回退版本时先从托盘退出当前工具，再运行保留的旧版；不要同时运行。

历史更新和技术验证保留在源码仓库。完整包包含程序、桥接副本、两份Word文档、深井搜索与学习说明、默认参数、启动说明、更新记录、校验文件和许可资料。
