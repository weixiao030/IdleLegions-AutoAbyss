适用：Windows 10 / 11，64 位，已安装 Steam 版 Idle Legions，已解锁深渊。

程序使用青色冰晶与向下箭头图标，EXE、系统托盘和浏览器页签一致。Windows 若缓存旧图标，可将新版解压到新的目录后运行；不需要重装桥接。

双击「IdleLegions自动下井.exe」。程序已包含 .NET 运行环境、前端和桥接脚本，玩家无需安装 Node、Python 或 .NET。

首次使用：

1. 正常关闭游戏。
2. 在控制台的「连接设置」点击「安装 / 更新桥接」。程序先备份用户配置，再添加自己的 autoload。
3. 点击「启动游戏」，正常登录，等待控制台显示「游戏已连接」。找不到游戏时填写 client.exe 完整路径，修改会自动保存。
4. 可先点「仅推演」，再点「单次下潜」或两个循环按钮之一。程序优先继续已经开始的深渊。

默认站位从前到后：狂战士、法师、弓箭手、圣骑士（图二）。在「策略参数 → 职业与站位」为前排、后排各两个位置自由选择职业，更改会与所有参数一起自动保存。全部 8 个职业均显示中文名：狂战士、弓箭手、治疗师、刺客、圣骑士、瘟疫医生、法师、十字军。同一职业只能上阵一次，选择已上阵职业会自动交换位置，也可使用前移、后移按钮。恢复默认也会自动保存。站位按最前到最后传入游戏，前排/后排表示靠前/靠后的两位。已有配置保持原顺序；新配置及恢复默认使用图二。自动保存完成后下次入场生效，已入场的深渊继续使用原队伍。运行中请先暂停再调整。未拥有的职业可保存为方案，但入场前需要更换。

选牌、购买和继承统一采用冻结异常构筑：先拿可继承普攻冻结，传说 `es_glaciar`（普攻冻结、每五次攻击弹跳）最优，其次普通冻结遗物或两冰冻结徽章。只有本层徽章时仍寻找可继承核心；缺核心先积累寒冷。已有普通核心时，优先升级传说核心；之后补开局护盾并继承，可继续叠加多个高级盾，晨昏系列同样适用。再补减速来源、减速增伤、异常状态增伤和更快弹跳；毒火的状态增伤、电毒的弹跳均可混搭。冰毒关键效果未出现时先选其他冰毒补充，再考虑暗影标记、已有标记时的标记加深和双暴。已有盾后仍可继续购买和继承高级开局盾；已有冻结核心时不重复优先选普通冻结牌。同档比较模拟收益。技能调整默认关闭。

普攻点燃与普攻带电始终硬性禁止，已知ID和实际效果描述均参与过滤，遗物、徽章、商店和继承入口统一执行；即使关闭所有偏好开关也不会自动选它们。只有禁牌时暂停，等待玩家处理。“回避明确消耗目标状态的效果”仅控制其他明确消耗状态牌的排序。火系被动增伤、电系弹跳可以正常拿。关闭“冻结与异常构筑优先”后其余按模拟比较，仍保留缺失冻结核心优先。

“优先跳过的精英怪”包含资料站全部 22 种精英（20 种大厅精英和 2 种伏击精英），支持搜索、多选和清空，默认不选，不选维持原路线策略。命中真实预览中的精英时，增加有限路线风险评分，候选理由显示名称。它不是禁行名单：唯一必经、所有分支都命中，或命中路线明显更安全时仍可前进，不因名单自动暂停。已进入房间后正常战斗。未知预览不猜怪物身份。名单更改会自动保存。

圣所优先级：倒地先复活；任何存活队员生命低于 60% 或平均低于 75% 时优先休息。全员生命至少 80% 且平均至少 90% 时，若魂力最低至少 50、平均至少 70，则优先磨利有已装备伤害技能的队员；魂力不足则先冥想。其余情况比较下一战模拟收益。磨利是指定一人的每层 +8% 技能伤害，随下潜保留，不加强普攻。选择队员时结合伤害技能系数、冷却、群攻和当前战斗预测。

本层徽章 es2_carambano 等只能证明本层有冻结，不能代替可继承的遗物。可继承核心覆盖 es_carambano、es_glaciar，以及明确说明普攻冻结的寒冷遗物。打赢首领后程序先处理徽章/遗物选择，再处理继承；每层只新增继承一张，之前继承的牌继续保留。同种牌已继承三张时不再叠加。程序不会把本层所有牌一起带下去：继承前重建旧遗物清单，优先确保冻结，继承后检查深度增加及每张应保留遗物的数量。状态不符会暂停，不重复派发继承。

持有普攻冻结效果时，默认在前 7 层自动缔结房间契约：游戏从 P0 计数，因此范围是 P0～P6。可自定义层数，0 表示关闭，或关闭自动缔约开关。契约会提高当前房间难度并增加奖励，按游戏确认回执执行。签约后会重新读取敌人预览。此参数只控制缔约范围，不限制下潜深度。

深渊回响等事件先过滤游戏标记为不可用的选项。魂力不足导致左侧缔约禁用时，选择右侧可用的“径直前行”，不再反复点击缔约；若所有选项都不可用则明确暂停。此事件选择与提高战斗难度的房间契约是两种独立操作。

默认自动跳过战斗播放，使用游戏原有“跳过”功能，实际胜负与奖励仍由游戏结算。可在策略参数关闭。

默认前 7 层（P0～P6）有普攻冻结核心时优先寻找战斗，争取“核心、碎屑”资源。之后优先避战，比较剩余路径的战斗数量；必经战斗照常打。缺少冻结核心时也优先避战。可独立设置奖励层数、奖励阶段开关、后续避战开关，以及核心资源与碎屑权重。权重表达路线偏好，不是已知掉落概率；默认核心权重 8、碎屑权重 4。契约层数和奖励层数是两个独立参数。禁止撤离时，失败可能损失本轮未结算收益，以游戏结果为准。

奥波币按本轮可用余额主动使用：有有效购买时先买后离店；生命/魂力有可恢复缺口即可补给，也支持碎屑兑换。卡牌与强化同不购买基线比较，未建模收益或诅咒代价的物品不盲买。每件商品只卖一次，售罄或无有效商品时可能保留余额。圣所会比较回血、补魂、复起和英雄磨利；磨利占用本次行动，每层增加 8% 技能伤害，普攻不变。

每个战斗或选卡候选默认实际运行 4096 次本地事件模拟，数值不设人为范围。非正次数关闭随机抽样，使用构筑和路线评分，不生成胜率；此时若启用最低胜率暂停线，战斗前暂停以免绕过该设置。安全移动等确定性转换无需随机战斗；其记录仍使用配置的试验数量。目标分配枚举所有合法组合，最多 4096 组，大量敌人时可能需要较长计算时间，暂停可取消尚未执行的推演。

模型从实际事件拟合敌人生命、出手与英雄伤害；按遗物可见描述、技能冷却和冻结时序比较组合。服务端引擎不可得，冻结时长默认 1 秒只是可调模型假设，并非游戏公开常量；敌人缩放、护甲、技能准备和部分遗物效果仍不完整。未解析效果会在候选诊断中列出，不虚构收益。预测区间只反映抽样误差，不包含这些模型误差，不保证真实胜率或全局最优。新增战斗会更新模型，报告保留预测误差。

控制页提供“循环 X 次”（不设人为范围）和“循环到绳索用完”。每次下潜一直到最深通关或战败后，先记录结算，再自动入下一次；次数模式遵守“保留绳索”，用完模式强制保留 0 根、不受次数上限影响，最后一根也会使用，到 0 根停止。暂停后“继续下潜”恢复原循环；直接点击另一个循环按钮会重新计算本次循环次数，并接着当前已有深渊。启动前自动等待参数落盘。

默认一直下潜到最深或战败，禁止撤离。停止深度及通关层数默认均为 0，表示不限；生命及胜率暂停线也默认关闭。设置自定义终点后，只暂停并保留深渊，不撤离。入场上限及保留绳索仍生效。所有参数可导入、导出。

暂停按钮等待已派发操作的回执后停止。服务器拒绝、未知状态、过期快照或超时会暂停，超时不自动重试。程序和桥接均拒绝撤离操作。程序只通过游戏原有操作入口执行，实际结果和资源消耗以游戏为准。

关闭网页不会停止程序；托盘菜单可以重新打开控制台、暂停或退出。退出不关闭游戏。

报告可在控制台下载；参数、日志、战斗数据保存在 `%LOCALAPPDATA%\FrostAbyss`。桥接和安装前备份保存在 `%APPDATA%\Godot\app_userdata\Idle Legions\frost_abyss`。

卸载：先停止自动流程并正常关闭游戏，再在「连接设置」点击「卸载桥接」。它只移除本工具自己的 autoload 行，保留其他插件与配置备份。

此发行包不包含游戏本体、反编译游戏脚本、美术、账户数据或登录令牌。游戏升级后接口变化可能需要更新桥接。

所有参数自动保存：停止编辑约650毫秒后写入本机配置，不再有保存参数、站位或路径按钮。状态提示显示保存进度；失败时保留草稿并自动重试，刷新可恢复待保存内容。正在保存也能继续编辑，早期响应不会覆盖新值。运行中请暂停后编辑。导入参数、恢复默认和控制页循环次数同样自动保存。

策略数值没有人为上下限；次数、种子、层数、深度、绳索和毫秒仍采用32位整数，权重与比例采用有限浮点数。空值、负号、未完成小数等中间态留在草稿里，完整后再保存，不静默转为0或截断。操作间隔默认1000ms，已有配置保留原值；非正间隔不额外等待，非正循环次数不新入场，非正层数关闭对应阶段。起始深度原样传给游戏，游戏自身允许的范围由回执决定。权重和比例按填写值计算，极大数值可能使模型无法产生有限结果，此时暂停并显示原因。

“模型假设：纯电伤清除冻结”默认关闭，可开启比较另一种假设。客户端公开的反应说明与回放尚不足以确定深渊服务端完整规则；已有火技能汽化事件也不能证明燃烧DOT清除冻结。家族标签不等于普攻附魔，电系弹跳允许；普攻点燃和带电无论假设开关如何都禁止。
