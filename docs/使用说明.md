首次使用：

1. 正常关闭游戏。
2. 在控制台的「连接设置」点击「安装 / 更新桥接」。程序先备份用户配置，再添加自己的 autoload。
3. 点击「启动游戏」，正常登录，等待控制台显示「游戏已连接」。找不到游戏时填写 client.exe 完整路径，修改会自动保存。
4. 可先点「仅推演」，再点「单次下潜」或两个循环按钮之一。程序优先继续已经开始的深渊。

默认站位从前到后：狂战士、法师、弓箭手、圣骑士（图二）。在「策略参数 → 职业与站位」为前排、后排各两个位置自由选择职业，更改会与所有参数一起自动保存。全部 8 个职业均显示中文名：狂战士、弓箭手、治疗师、刺客、圣骑士、瘟疫医生、法师、十字军。同一职业只能上阵一次，选择已上阵职业会自动交换位置，也可使用前移、后移按钮。恢复默认也会自动保存。站位按最前到最后传入游戏，前排/后排表示靠前/靠后的两位。已有配置保持原顺序；新配置及恢复默认使用图二。自动保存完成后下次入场生效，已入场的深渊继续使用原队伍。运行中请先暂停再调整。未拥有的职业可保存为方案，但入场前需要更换。

普攻冻结确认继承前，正常候选优先只拿冰系，包含冰减速；本章刚取得冻结或仅有临时徽章，都不提前切换火系。冻结未确认继承前，允许优先多拿普攻冻结；本章已经拿到同ID、其他冻结变体或临时冻结徽章，都不因为重复而排除或降权。普通冻结维持2000，冻结附带5次全体弹跳维持2200，高于其他冰牌1950；仍优先冰系，不让火系或非冰弹跳提前抢选。只有下一章回执确认已经继承一份冻结后，才结束收集阶段：纯冻结正常不再重复拿，带新增/更快弹跳或其他有效增益的混合牌按既有权重、重复降权和护盾偏好比较。 多拿只改变选牌偏好，不把冻结布尔效果模拟成多倍伤害或更高触发率，也不伪造具体继承概率。每章仍只新增继承一张，不宣称多拿的冻结会全部带入下一章。实际游戏不可用项不派发，策略候选筛空仍沿用择优兜底，不要求玩家手动处理。确认继承后依次优先新增/更快全体弹跳、独立普攻各一份、引爆器一份、火增伤、其他输出和少量防御；优先避开冰减速与多余冰伤。按玩家反馈用冰系积累系列倾向，但没有编造服务端抽取概率。

已有燃烧并不代表另一张燃烧牌整张无效：例如截图第三张“烈焰”（br_incendio）还附带伤害+4%，独立燃烧不重复加分，但这部分可识别数值仍可比较。无新增独立效果、无弹跳但有附带数值的重复状态牌额外减600，避免压过更好的新输出；同ID每份另减350。纯重复状态正常避让，引爆器仍优先只留一份。

所有选牌偏好统一支持择优兜底：正常候选为空时，只从游戏实际可选卡中放宽偏好、扣分比较，不因前X层护盾、独立开关、重复状态、仅冰阶段或继承叠层偏好而暂停。前X层护盾改为“优先不选”，默认开启、7层（P0～P6）；实在无合适选择可以拿盾。兜底会显示原避让原因及扣分。游戏标记不可用、缺ID、余额不足、请求失败或回执异常不能靠兜底冒充成功；没有任何游戏可用选项时保留状态保护，不杜撰接口。

在「策略参数 → 普攻状态」分别设置允许普攻点燃和允许普攻带电，默认点燃开、带电关；正常候选只影响对应普攻施加状态，其他火电增益照常比较。关闭冻结与异常构筑优先只改变后期排序，不解除前期冰系优先；所有偏好无正常候选时统一兜底。

圣所优先级：倒地先复活；任何存活队员生命低于 60% 或平均低于 75% 时优先休息。全员生命至少 80% 且平均至少 90% 时，若魂力最低至少 50、平均至少 70，则优先磨利有已装备伤害技能的队员；魂力不足则先冥想。其余情况比较下一战模拟收益。磨利是指定一人的每层 +8% 技能伤害，随下潜保留，不加强普攻。选择队员时结合伤害技能系数、冷却、群攻和当前战斗预测。

本层徽章 es2_carambano 等只能证明本层有冻结，不能代替可继承的遗物。可继承核心覆盖 es_carambano、es_glaciar，以及明确说明普攻冻结的寒冷遗物。打赢首领后程序先处理徽章/遗物选择，再处理继承；每层只新增继承一张，之前继承的牌继续保留。同种牌已继承三张时不再叠加；正常候选避让满层牌，若被迫兜底选择也不会在预测中增加第四份。程序不会把本层所有牌一起带下去：继承前重建旧遗物清单，优先确保冻结，继承后检查深度增加及每张应保留遗物的数量。状态不符会暂停，不重复派发继承。

持有普攻冻结效果时，默认在前 7 层自动缔结房间契约：游戏从 P0 计数，因此范围是 P0～P6。可自定义层数，0 表示关闭，或关闭自动缔约开关。契约会提高当前房间难度并增加奖励，按游戏确认回执执行。默认独立开启“跳过前8次受击免疫契约”（Costra / costra）和“跳过15%闪避契约”（Escurridizos / escurridizos），可分别关闭。Costra 的可见描述是每个敌人前8次受击无效；跳过签约仍正常打房间，已经签约的效果不会撤销。签约后会重新读取敌人预览。此参数只控制缔约范围，不限制下潜深度。

深渊回响等事件先过滤游戏标记为不可用的选项。魂力不足导致左侧缔约禁用时，选择右侧可用的“径直前行”，不再反复点击缔约；若所有选项都不可用则明确暂停。此事件选择与提高战斗难度的房间契约是两种独立操作。

默认自动跳过战斗播放，使用游戏原有“跳过”功能，实际胜负与奖励仍由游戏结算。可在策略参数关闭。

默认前 7 层（P0～P6）有普攻冻结核心时优先寻找战斗，争取“核心、碎屑”资源。之后优先避战，比较剩余路径的战斗数量；必经战斗照常打。缺少冻结核心时也优先避战。可独立设置奖励层数、奖励阶段开关、后续避战开关，以及核心资源与碎屑权重。权重表达路线偏好，不是已知掉落概率；默认核心权重 8、碎屑权重 4。契约层数和奖励层数是两个独立参数。禁止撤离时，失败可能损失本轮未结算收益，以游戏结果为准。

奥波币按本轮可用余额主动使用：有有效购买时先买后离店；生命/魂力有可恢复缺口即可补给，也支持碎屑兑换。卡牌与强化同不购买基线比较，未建模收益或诅咒代价的物品不盲买。每件商品只卖一次，售罄或无有效商品时可能保留余额。圣所会比较回血、补魂、复起和英雄磨利；磨利占用本次行动，每层增加 8% 技能伤害，普攻不变。

每个战斗或选卡候选默认实际运行 2000 次本地事件模拟，数值不设人为范围。非正次数关闭随机抽样，使用构筑和路线评分，不生成胜率；此时若启用最低胜率暂停线，战斗前暂停以免绕过该设置。安全移动等确定性转换无需随机战斗；其记录仍使用配置的试验数量。分别锁定默认优先比较均衡分散组合；关闭后比较自由分配，超大菜单最多比较前4096个合法候选（不宣称全局最优），不因组合过多暂停，大量敌人时可能需要较长计算时间，暂停可取消尚未执行的推演。

模型从实际事件拟合敌人生命、出手与英雄伤害；按遗物可见描述、技能冷却和冻结时序比较组合。服务端引擎不可得，冻结时长默认 1 秒只是可调模型假设，并非游戏公开常量；敌人缩放、护甲、技能准备和部分遗物效果仍不完整。未解析效果会在候选诊断中列出，不虚构收益。预测区间只反映抽样误差，不包含这些模型误差，不保证真实胜率或全局最优。新增战斗会更新模型，报告保留预测误差。

控制页提供“循环 X 次”（不设人为范围）和“循环到绳索用完”。每次下潜一直到最深通关或战败后，先记录结算，再自动入下一次；次数模式遵守“保留绳索”，用完模式强制保留 0 根、不受次数上限影响，最后一根也会使用，到 0 根停止。暂停后“继续下潜”恢复原循环；直接点击另一个循环按钮会重新计算本次循环次数，并接着当前已有深渊。启动前自动等待参数落盘。
