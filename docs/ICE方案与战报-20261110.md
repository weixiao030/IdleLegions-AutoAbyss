# ICE 方案与战报说明（v1.3.6，2026-11-10）

本说明随v1.3.6发行包提供。解压后运行 EXE，网页顶部可核对版本号；运行方式与开始/暂停操作集中在控制页。升级前退出旧工具，桥接更新步骤见文末。

## 选择顺序

1. 未确认继承前优先普攻冻结核心与冰系，临时冻结徽章不替代继承。
2. 确认继承后，补缺少的每4/5/6次全体弹跳，分别保留三档；再补每8/10次必暴击。已有对应档时不重复抢占必拿优先级。
3. 按六图指定效果优先。卡号严格为截图从左到右1–3，程序不存菜单位置。
4. 继续补齐七个系列各8张遗物；无指定偏好时优先张数较少的未满系列。徽章不补遗物张数，章末继承只按真正旧遗物计进度。同种三层继承上限、实际可用性及独立普攻开关继续生效；没有合适偏好时从游戏实际可选项择优兜底。

## 战报口径

- 输出仅来自己方伤害事件；承受伤害来自敌方事件。结算生命损失 `result.sima.dano` 单列，不混成输出。
- 暴击、技能、反应统计命中事件数。截断日志仅提供不完整下界。
- `rel` 事件统计直接触发伤害及零伤害触发，不把常驻增伤归因为可精确分割的伤害比例。
- 核心、碎屑、奥波币使用操作前后快照差分，缺快照记未确认。每场原始回执保存在 `battles/`，取得卡牌使用成功选择回执。
- 桥接0.3.3保留操作对应的独立结算收据 botin.piezas，记录实际装备名称、ID、稀有度，并通过客户端 NombreObjeto.de 获取当前语言显示名。没有收据时记录背包新增并明确差分来源，不归因为某只怪物掉落。邮寄/待领取神话只有数量时不猜名称；旧桥接和旧记录缺字段保持未确认。
- 角色输出增加占比、按参战时长加权的DPS和结算生命损失覆盖场数；来源按反应、遗物、技能、其他互斥归类。卡牌直接触发同时显示占已标记触发及占全队输出两种比例，不能当作常驻增伤净贡献。
- 单轮角色汇总可在战绩页展开；分析提示依据截断情况和战败场结算生命损失给出核对方向，不宣称最优配装。跨章暂存战利品重置不作为资源损失。
- 重启仅恢复 `last-session.json` 的战斗/卡牌展示，不恢复自动执行。重新开始新会话会重置当前段统计，历史Markdown及原始回执保留。
