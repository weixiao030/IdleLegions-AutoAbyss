# 1.3.0 发布验证

日期：2026-11-09；Windows x64。所有本轮检查使用隔离配置与离线样例，没有消耗玩家绳索、资源或运行新战斗。历史实战不计入本版成绩。

## 功能

- 策略数值移除产品的人为上下限；默认操作间隔1000ms。整数格式、有限数值、四职业不重复和已知精英ID仍校验。
- 参数、站位、精英名单、路径、导入和控制页循环次数统一自动保存，串行合并连续编辑；失败保留草稿并自动重试，刷新恢复草稿；启动动作等待保存成功。
- 优先继承首个普攻冻结核心，允许从普通升级传说五次弹跳；已有核心不重复抢名额。高级开局护盾继续购买和继承，不限一张。
- 普攻点燃/带电按ID及效果描述硬过滤，遗物、徽章、商店、继承统一执行；关闭偏好也不可绕过，只有禁牌时明确暂停。火被动增伤、电系弹跳可正常选。
- 纯电伤清除冻结的机制尚未获深渊服务端证据；模型提供两种假设，默认不清除。客户端组合界面读取consumes字段并不是服务端战斗逻辑，直接火技能汽化也不能证明燃烧DOT消耗冻结。

## 本地验证

后端121项自测通过，包括全部旧回归及本次范围、继承、高级盾、禁牌、零抽样、两种电伤假设。全部1680种四职业组合及22种精英映射继续覆盖。

浏览器36项检查通过，覆盖快速编辑、请求中继续改参数与职业、失败草稿刷新和自动重试、导入、路径启动前flush、控制页同步、运行中禁用，以及1440/1024/768/390宽度布局。浏览器验证脚本位于tools/formation-integration；实际生产HTTP处理器和嵌入前端运行于隔离profile，游戏启动请求被拦截。

精英多选另有41项浏览器回归通过，覆盖全部22种逐项勾选、搜索、键盘选择、刷新恢复、非法ID拒绝、失败自动重试及运行中禁用。两套浏览器检查在独立会话运行。

构建通过build.ps1产生自包含EXE；package_release.py按白名单打包并逐文件核对SHA-256及ZIP完整性。GitHub Actions在正式推送后另行核验。

## 限制与恢复

不设人为范围不代表游戏接受任意深度，也不代表模型无限精度；非正抽样关闭胜率估计，非正间隔无额外等待，非正循环次数不新入场。计算无法产生有限结果时暂停，不偷偷截断参数。现有设置保留，升级不重置间隔。职业更改下次入场生效。游戏本体、PCK和玩家配置未被本轮测试修改。

回滚可解压v1.2.1到独立目录使用；自动保存写入前可先导出当前参数留存。
