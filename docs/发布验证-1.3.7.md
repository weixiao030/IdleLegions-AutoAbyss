# v1.3.7 发布验证

日期：2026-11-10。Windows x64 自包含发行，桥接保持0.3.3。

## 变更与验证范围

- 参数分组、维护与恢复、关于与支持、单轮角色汇总默认展开；手动收起后，状态轮询不会重新打开。
- 逐层逐角色、卡牌触发、资源变化、装备和已取得卡牌明细，每页10条，提供上一页、下一页、页码及总条数。按显示行分页，保留同层多次战斗。筛选改变回到第一页，轮询新增保留当前页，数据减少时修正页码。
- 装备表仅显示明确为mythic的新增神话装备和正数神话邮寄/待领取记录；其他稀有度、未知稀有度、无新增操作不占行。不按名称猜测稀有度，不改标或删除原始物品。
- 全量汇总、占比分母、原始回执、归档和完整Markdown报告不受网页分页和神话过滤影响。三套策略、默认参数、桥接及游戏操作未修改。
- 战报输出、DPS、承伤、结算生命损失、输出来源、卡牌触发伤害和资源增量统一使用万/亿单位；DPS显示/s，悬停查看精确数值。角色与卡牌伤害占比增加进度条，按完整筛选范围的实际百分比绘制。
- 前端13项单元测试通过，覆盖10/10/8分页、边界、数据缩小、神话过滤、空装备、缺名神话、邮寄计数、万/亿边界舍入、精确值和占比分母。
- 浏览器162项隔离检查通过：36项数值与进度条检查，64项报告与过滤检查，62项控制页回归。使用模拟API验证，未向真实游戏派发命令。覆盖深浅色、390/768/1024/1440px、筛选重置、轮询、全量导出及运行锁。
- Windows自包含EXE默认隔离自测1687项通过；未进行新版真实下井或真实神话掉落实测。
- 前端构建成功；Vite存在第三方组件use-client及包体积提示。网页、EXE、打包脚本和CI版本统一为1.3.7。

## 使用与回退

解压完整包，先从托盘退出旧工具，再双击EXE。自带运行环境，无需安装Node.js、Python或.NET，保留现有参数与历史记录。

本次不需要重装桥接。若此前未安装0.3.3且需要装备证据，先正常关闭游戏，在连接设置安装/更新桥接，再启动登录。包内bridge/frost_bridge.gd是EXE内嵌脚本的同版副本，正常使用无需手工复制。

回退时从托盘退出新版后启动旧版；不要同时运行两个控制器。更新过桥接时，可关闭游戏后恢复安装时的配置备份。

## 发行完整性

Windows CI对发行提交运行前端单元测试、构建、自测和打包。ZIP按白名单包含EXE、桥接源码副本、说明文档、更新记录、许可证及逐文件SHA-256清单；外附.zip.sha256和SHA256SUMS.txt。打包器校验ZIP CRC、文件数量及每个文件哈希。本地账号快照、日志、游戏源码与测试夹具不发布。
