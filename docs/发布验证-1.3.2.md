# 1.3.2 发布验证

日期：2026-11-10。基于1.3.1（212bf37）更新；桥接仍为0.3.2。本文记录本机验证，CI状态另见相应提交的Windows build，不把开发验证写成新版实战通关。

## 本版改动

- 普攻点燃、普攻带电拆为两个独立Radix开关，默认火开、电关；自动保存、刷新、导入导出、旧配置及运行锁全部覆盖。只改变自动选择，不删除游戏卡、不改游戏本体、不移除已有卡。
- 首个冻结只拿一份并继承，随后依次优先新增/更快全体弹跳、独立普攻各一份、引爆器一份、火增伤、其他增伤、普通输出及少量防御。尚无冻结时冰系兜底不压过弹跳，本章已拿冻结不继续堆冰。
- 引爆器已有即硬跳过，四入口一致；不会因变体附带数值再次拿或继承。冻结继承后冰减速硬性排除，即使强制菜单只剩它也明确暂停；冰伤软避让，强制仅剩冰伤可兜底。前X层护盾限制不变，默认前7层P0～P6。
- 新增弹跳按触发次数分级；重复数值每份减350，已有同档/更慢弹跳另减175（混合牌新增独立效果时不误扣旧弹跳罚分）。三份上限不变，不追重复冻结升级。
- 根据真实字段区分可继承遗物和本章徽章，llegada.reliquias入章数量优先还原旧继承。继承回执核验后，以实际新章保留卡进行本地普通房间先验复核，不重放旧Boss、不把深度再加一，不发额外游戏请求。
- 具体策略权重、分支条件、降权及模拟限制见《模型说明》1.3.2章节。

## 实际执行的验证

1. build.ps1：Vite前端及.NET 8 win-x64自包含EXE构建通过。Radix依赖的use client指令被Vite忽略的构建警告仍存在，不是构建失败。
2. 发行EXE --self-test：247项通过。新增CardSelectionTests检查真实ID/中英西描述、四入口独立开关与去重、引爆器变体硬去重、5/16次弹跳排序、数值降权、冰减速硬禁、前期冰系不压弹跳、最终权重数值、旧配置和原始牌不变。
3. CardFlowTests使用隔离文件桥接运行真实Pilot.Step：遗物→临时徽章→章末继承共3个请求，下一章本地复核64次并写入chapterReviews；无第四个消费请求。徽章不进入保留列表；关闭抽样时不生成胜率。
4. 真实浏览器运行tools/formation-integration/card-rules-check.cjs，24项通过：两开关、自动保存刷新、导入导出、旧配置、键盘、运行中前后端锁定、最终策略文字。1440/390两种宽度及浅/深主题共4种布局无横向溢出，双开关可见，未处理页面异常为0。
5. 离线遍历本机1016个历史JSON文件，对14个不同继承快照比较llegada前缀与旧候选外遗物/llevas重建：14/14一致，无不匹配。这是历史字段验证，不是1.3.2实战。
6. 用户的火系构筑截图仅作本地参考，测试采用独立构造的描述验证状态去重、5次与20次弹跳及重复火数值降权，未照抄完整卡牌构筑。
7. npm锁文件第三方依赖与1.3.1保持完全一致，仅应用自身版本改为1.3.2。发行脚本使用明确白名单，不收录玩家数据、日志、历史回执、截图或反编译游戏代码。

本机原始结果位于忽略目录output/cards-1.3.2，截图位于output/playwright/cards132；不放入发行包。发布脚本逐项校验ZIP内部文件和SHA256SUMS，同时生成ZIP校验文件；发布资产可用相应SHA-256核对。

## 边界与升级

未启动真实游戏进行1.3.2资源消费或通关测试，没有新的实战胜率结论。本地模拟是近似模型，置信区间不包含机制误差；多个弹跳来源按当前已解析的最快周期近似，不保证服务端精确叠加。冰减速是否影响冻结触发仍未证实，本版按玩家偏好避让，不编造概率。

每章只新增继承一张，不能保证本章新取得的所有独立效果都同时带走；临时徽章跨章清空，不能通过本工具改成永久遗物。硬规则导致无合法候选时会明确暂停，可手动处理后继续，不虚构游戏跳过接口。

从1.3.1升级：退出旧工具，解压并替换新版EXE即可；已有配置保留，新增字段缺省火开电关。桥接仍为0.3.2，不需要重装；若来自更旧桥接版本，按使用说明正常关闭游戏后安装/更新桥接。升级不会移除之前已经持有或继承的重复牌。
