# 策略四自定义选牌

从左侧“自定义选牌”进入配置页。修改会自动保存，页面右上角显示保存结果；只有选用策略四才会应用这些规则。

## 固定前置

开局优先寒冰，最优先普攻冰冻。继承菜单有普攻冰冻就优先带走；没有则按1.3.1参考规则择优继承过渡遗物，正常进入下一层继续寻找。下一章到达回执确认普攻冰冻遗物已继承后，才启用自定义排序。在此之前自定义偏好不改变固定前置或过渡规则；临时徽章、本章新牌及普通冰系过渡遗物均不能充当冰冻继承确认。

## 如何排序

依次比较系列、该系列的细分类、同类单卡。数字1最高，2其次，以此类推；单卡数字不会跨系列、跨细分类抢位。

- 系列和细分类：长按左侧手柄约三分之一秒，然后拖到目标位置松开。也可用上下移按钮，或聚焦手柄后按上下方向键、Home、End。退出键可取消拖动。
- 单卡：填写优先级。默认每个系列从1起连续编号；数字相同才比较推演收益。
- 目标张数：达到后软避让；0表示不限。遗物、临时徽章和商店赐福独立统计。
- 拉黑：平时排除；强制菜单只有拉黑候选时作为最后兜底，择优选择并继续。商店不为拉黑兜底消费。
- 软避让：强制菜单没有正常候选时才兜底，优先于拉黑候选；商店不会为兜底卡花钱。

强制菜单按正常候选→软避让→拉黑末位兜底，目标张数或重复效果均不造成偏好暂停。继承优先未达三张上限的候选；全部已满而游戏仍允许选择时，正常选一张推进，核验原遗物保留，不虚报新增张数。游戏声明不可用的选项、网络回执异常及用户设定的运行停止条件仍保留原保护。

默认值读取1.3.1冻结实现，以“已经继承普攻冰冻、尚无开局盾”的状态生成静态参考，体现护盾、弹跳、减速增伤、状态增伤、标记及输出等偏好。仍按上述三层比较，不会动态复刻1.3.1的全部决策。普攻点燃和带电按1.3.1参考默认拉黑，可以在策略四自行解除。策略一、二、三及1.3.1实现均不受影响。

## 导出与导入

“导出选牌”下载策略四专用JSON文件，包含完整系列顺序、细分类顺序、单卡优先级、目标张数、拉黑及软避让配置。默认值也一并保存。

“导入选牌”只接受本工具版本1的策略四专用文件，导入后自动保存。不会切换当前策略，也不会修改模拟次数、站位、下潜范围等参数。错误文件会显示原因，保留原配置。正在下潜时只能浏览和导出，暂停后才能修改或导入。

## 卡牌资料

本地当前版本七系列共151张：88张遗物、63张徽章。卡图来自本机游戏资源，名称与效果使用游戏自带中文翻译，并逐项核对真实菜单回执；全部已核实。服务端后续新增卡以实际回执为准。

所有配置折叠区默认展开，可以手动收起。
