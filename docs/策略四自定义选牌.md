# 策略四自定义选牌

版本1.5.1。只在选中策略四时生效。

## 选牌阶段

策略一、三、四优先取得并继承冰川（冻结＋每5次全体弹跳）；没有冰川时先补冰系至4张。普通冻结不重复置顶，有新增冰伤、减速或弹跳时比较实际增益。先继承火或毒也不会跳过冰系前置。随后补齐冰、火、电、毒、暗影、光耀、钢各4张；已满系列让位，七系全部达标后忽略手动系列顺序，按单卡新增收益比较。

获取和继承分别计数，徽章赐福不计遗物张数。冰锥遗物与2张羁绊冰锥分开显示。

## 光系可选配置

策略四“光系只继承普攻狂热”默认关闭。需要时在“自定义选牌”点击“使用此配置”，优先保留狂热（au_fervor）、连祷（au_letania）各一份，再补其他系列。其他光牌仍可在本层凑羁绊，章末优先不继承；仅剩光牌的强制菜单会合法过渡。点击“关闭此配置”可恢复原行为。启用和关闭都不改动已有单卡配置，其他策略不读取此开关。

## 自定义顺序与兜底

默认收益比较；手动模式按系列、细分类和单卡顺序选择未满系列。全部七系4张后忽略系列顺序。软避让、拉黑、目标张数仍生效。默认顺序来自经典1.3.1静态参考。

强制菜单按正常、软避让、拉黑末位逐级兜底，实际不可用项不恢复；商店无合适项直接离店。同种最多继承三张，本层获取不误用此上限。

## 分享配置

导出选牌保存比较方式、排序、单卡和光系开关。旧文件缺光系字段按关闭导入；旧文件缺模式仍按原系列排序解释。导入不切换策略或覆盖其他参数。运行中锁定编辑和导入，暂停后可修改。
