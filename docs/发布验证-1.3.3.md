# 1.3.3 本地构建与验证

日期：2026-11-10，基于1.3.2（09a92c27059161a0c58da583631bfb49ce8b69fe），桥接仍为0.3.2。本轮只交付本地新版，未执行新一轮push或线上发布，不将旧CI或历史战绩写成1.3.3的结果。

## 改动

- 冻结确认继承前正常只选冰系，拿到本章冻结或临时徽章不提前转火；无合适冰牌时执行择优兜底。
- 护盾改为前X层优先不选，默认7层，统一遗物/徽章/商店/继承四入口。所有选牌偏好无正常候选时恢复实际可用项并降权比较，不要求玩家手动处理策略冲突。
- 修复用户截图烈焰的附带伤害被重复燃烧整张过滤：布尔状态不重复加分，可识别附带数值仍可降权比较。冻结继承后默认火开、电关，截图的第三张会被正常选择。
- 补全6项用户指定配置提示，参数字段和原值兼容，不假装按电脑/网络自动测量或改配置。
- 商店不超余额或重复买；可正常离店。兜底满三份牌不伪造第四份继承收益。

## 实际验证

1. build.ps1：React/Vite前端及.NET8 win-x64自包含EXE构建通过。Vite保留依赖的use client指令忽略警告，不是构建失败。
2. 发行EXE --self-test：378项通过。新增IceOpeningTests、FallbackSelectionTests，并更新旧暂停断言为实际兜底行为，原复活、网络超时及回执保护继续通过。
3. 冰系阶段覆盖四入口及空开局、本章取得冻结、临时冻结徽章、旧火牌加本章冻结；正常有冰时不让非冰弹跳火增伤抢选，确认继承后才放开后期排序。
4. 统一兜底覆盖仅盾、仅冰减速、纯重复独立状态/引爆器、关闭的普攻、三份上限、多重偏好冲突、空菜单、实际不可用项、余额不足及售罄；仅策略无候选不暂停。
5. 截图三选一按带电/10%盾/燃烧附带4%伤害重建，前20层护盾偏好与已有燃烧同时存在，四入口选择第三张；已有同ID、继承前有冰/无冰也覆盖。真实Pilot.Step加隔离桥接确认派发第三张烈焰成功，不是只测评分函数。
6. CardFlowTests真实生产状态机：三张冰遗物→仅剩护盾兜底→临时徽章→冻结继承，共6步；章末按新章保留构筑本地重推演64次，无额外消费请求。随后另跑截图菜单派发回归。
7. 真实浏览器32项通过：6项配置提示、优先避盾和全策略兜底、火电独立开关、自动保存刷新、导出导入、旧配置、键盘、运行中前后端锁；1440/390宽度×浅/深主题无横向溢出，未处理页面异常0。已人工查看桌面浅色与窄屏深色截图。
8. 依赖与发行白名单校验由tools/package_release.py及本机核验执行；不收录玩家数据、日志、截图、回执或游戏反编译代码。发行ZIP内部SHA256SUMS逐项校验，ZIP另生成SHA256文件。

本机原始验证位于忽略的output/cards-1.3.3，浏览器截图位于output/playwright/cards133，修改前源码备份在backups中；这些均不放入发行包。

## 限制、升级及回滚

没有启动真实游戏或消费玩家资源进行1.3.3实战，不能把测试成绩当作真实通关率。系列倾向与减速影响冻结的具体服务端结算未证实，不编造概率。本地推演是近似模型。

所有策略兜底只针对偏好，真实不可用、资源不足、请求失败、继承/复活回执不一致仍保留保护，避免重复消耗。自定义生命/胜率/终点暂停线和玩家主动暂停仍有效，不等于“策略无牌可选暂停”。

从1.3.2升级，暂停并退出旧工具，解压并运行新版EXE，继续现有深渊即可；原配置保留，旧护盾字段改为软避让含义，桥接无需重装。回滚时退出工具并换回保留的1.3.2 EXE；不需要删玩家存档或遗物。
