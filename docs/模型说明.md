# 深井模型与策略说明 1.5.1

本地模型根据客户端描述、游戏回执和历史战斗近似预测，用来比较候选行动。服务端完整战斗引擎不可见，模型仍明显低估历史胜率，不能视为精确复刻。实测误差、算法及训练门槛见《深井搜索与学习-1.5.1.md》。

## 深井状态与跨层规则

一层依次经过路线、房间、战斗或服务、奖励与首领；通关后的继承会改变楼层run ID，但仍属于同一次下井。每层新增继承一张遗物，旧继承遗物保留，每种最多三张。本层拾取是否可选由真实菜单决定，不把三张上限误用为本层抓牌上限。

徽章按系列门槛处理：继承后的该系列遗物数量仍达到徽章umbral时保留，失去门槛的徽章不投影到下一层；新达到门槛可能触发新徽章菜单。商店赐福跨层清空。827组严格筛选的历史过层候选支持该规则，尚不等同于全部经过完整连续episode验证。

冻结继承以llegada所指到达遗物为依据；新抓到冻结或徽章提供冻结均不冒充已继承遗物。旧数据缺少到达字段时按兼容规则处理，无法确认时不伪造。

## 策略一二四的抓牌修正

一、二保留各自规则，修复继承识别及纯重复冻结偏置；二保留经典战斗模型，但不再标成未修改1.3.1原版。混合牌仍比较附带收益。

四默认“收益比较”，继承冻结后跨系列比较新增效果；主动启用“系列排序”才按系列、细分类、单卡顺序。旧版专用导出文件缺模式时保留旧系列排序含义。强制菜单筛空仍择优兜底，商店不为兜底消费。

## 战斗推演

主模拟使用事件队列分别计时普攻和技能；施法不替换一次普攻。冷却已结束但魂力不足时等待魂力，获得魂力后从当前时间施法。战斗观察窗口为180.2秒，并设事件数保护；这来自可见约180.1秒战报的边界，不是对服务端精确tick的断言。经典模拟器继续保留自己的事件模型。

历史技能缺damages标记时，按敌方目标和伤害描述识别；盟友增益或明确非伤害标记不误作攻击。眼泪复活为50%生命且魂力归零；圣所读取实际levantaPct。跨层按保留的生命效果重算hpMax和hp。

敌人生命、伤害与节奏优先来自已见同类样本，按深度和行数近邻缩放。永久冻结下未观察到伤害是截尾样本，不当作敌方攻击力为零。历史推演使用战前冻结英雄属性和技能；缺上下文则跳过，不能拿当前账号替代。

## 搜索与实战学习

五用纯UCT树搜索；六在UCT上使用历史战斗模型及已确认决策残差校准；七在通过整次下井留出验证后使用策略和价值网络参与PUCT，冷启动仍用UCT。搜索前推不派发游戏动作。

未知地图、菜单、商店从已见样本采样，采样频率不是服务端掉率。事件或契约后果未完整建模时截止该条前推。五至七尊重深度、通关层数、低生命暂停线，先处理已获得的强制选牌。

所有策略记录候选特征、已选项、前后快照、命令回执和策略来源。只有已确认且整次结束的轨迹进入网络训练；未知结果保留审计，不当成成功。旧战报用于战斗模型，不伪造缺失的决策标签。

## 仍有的误差

冻结和状态反应精确时序、敌方技能、持续伤害、护盾细节、契约及事件并未完整复刻。多个弹跳周期按近似覆盖处理。强度和冻结时长参数是模型假设；蒙特卡洛置信区间只反映抽样误差，不包含这些模型偏差。扩大搜索预算或购置GPU都不能消除规则缺失。
