# 1.3.2 模型说明

1.0 沿用 0.4.3 的模型与策略，以下证据及边界说明来自 0.4.3，未将历史验证视为 1.0 新增实战。

## 0.4.3 模型证据与边界

- 原游戏未修改；使用客户端现有正常深渊操作及战斗回放事件。
- 已读客户端 sima_panel.gd 的请求流程和 battle_view.gd 的 `_teatro_srv` / `_srv_con_puerta`。这些来自 2026-11-03 提取的版本，只作架构线索；当前运行的结果由真实事件核对。
- 深渊结算在服务端；没有取得服务端引擎或全部敌人属性，不能声称精确复刻。
- 真实事件字段：t、side、src、dst、dmg、hpPct、crit、skill、reaction、est、sest、rel。dmg<0 为治疗。冻结标记 congelado；火消耗冻结的 reaction 为 vaporizacion。
- 核心 ID 已实测出现 es_carambano、es2_carambano；es_glaciar 描述也包含普攻冻结。普通寒冷牌不再硬排在其他系列前。
- 当前卡牌效果从玩家可见 desc 解析：攻速、生命、防御、条件增伤、护盾、吸血、击杀治疗、减速、群攻周期和普攻状态。未解析部分列在候选诊断里，不伪造效果。
- 冻结是普攻触发，不存在无核心随机冻结。直接火技能触发汽化按历史事件近似；燃烧DOT不据此推断为清除冻结。1.3起纯电伤的清除行为为可切换的待确认假设，默认不清除。
- 敌人 HP 从累计伤害与 hpPct 回推；输出从事件拟合。全程被冻、没有出手的敌人是删失样本，不当成零攻击力。冰冻间隙的短暂爆发不再直接外推为全程持续 DPS。
- 默认冻结时长 1 秒是未识别服务端参数的模型假设，可调并进行随机敏感性抽样；非游戏官方常量。
- 敌人层间/房间缩放、施法准备、伤害减免、DOT、光暗反应和保护技能尚非完整引擎；采用经验估计与宽泛不确定性。技能描述系数及冷却参与时序，部分行为无法确认。
- 37 场按时间先预测后学习：开发初版 Brier 0.2243，修正短爆发外推后 0.0711。此批已用于调参，是开发诊断，不是独立留出验证。当前角色技能近似历史槽位、目标由首击反推，是额外限制。
- 新的真实下潜结果作为后续验证，报告保留误差和资源收益，不声称反事实全局最优。
- 奖励指 botin.nucleos（核心资源）及 botin.esquirlas（碎屑），不把奥波币或遗物数量替代资源收益。掉落率未知，路线权重仅表达偏好。
- 最终开发审计 43 个评估样本平均 Brier 0.059025，仍是开发数据。稳定模型 D 的后续真实记录为 26 场、25 胜 1 负，Brier 0.049345；整轮含旧版阶段共 47 场、46 胜 1 负，P9 战败，核心净增 2、碎屑净增 3，撤离 0。
- 实测结束后追加报告战斗标识去重、迷雾转战斗空预览刷新；最终构建 40 项自测通过。该缓存修复未重跑一轮全程实战，不宣称它能改变 P9 的失败结果。

0.4.1 新增低血防御语句别名，继承改用下一层普通房间先验，排除刚击败的首领。0.4.2 新增商店不购买基线及先买后走、小缺口补给、碎屑服务、圣所磨利和 Rencor 条件增伤。消费额从确认前后余额计算。47 项自测通过；本次 5 把结果及版本范围以实测报告为准。前文旧版开发集结果保留作历史证据。

0.4.3：构筑排序按最新要求固定为缺失可继承冻结核心 → 暴击/暴伤 → 伤害与弹跳；缺可继承核心时积累寒冷，本层徽章不代替可继承遗物。排序优先级与战斗胜率分开，不把系列牌更多带来的概率变化编成具体数值。

继承输入来自 guardaPendiente.cartas、候选的 llevas、run.reliquias。候选清单只描述本层可新增的牌，不能用它替代全部已继承清单。候选外旧牌及候选中 llevas 份旧牌保留；再新增所选一张（每种最多三张）。下一深度回执逐张核验，不把 blasones 或 buffs 当成跨层遗物。客户端反编译的 _eleccion_pendiente / _reliquias_mesa / _guarda_mesa 提供历史参考；当前游戏真实回执才用于确认实际行为。

循环控制新增次数/用尽绳索模式；隔离回执集成测试只验证状态机，不计入真实战斗统计。0.4.3 的真实两次循环和继承核验结果另见本版实测报告，前文历史版本数据不混入本版成绩。


## 1.2 策略与模型变化

构筑顺序更新为缺失可继承冻结核心、传说冻结五次弹跳升级、一个可继承开局护盾、减速来源、减速增伤、异常增伤和弹跳；冰毒补充优于暗影标记与双暴。旧版双暴优先仅是历史记录。购买不重复追第二张开局盾；本层徽章仍不能代替下层可保留的核心或护盾。传说毒弹跳的复数描述、10% 更慢别名、晨昏护盾短句均加入解析。火雷回避只针对实际消耗状态的普攻，保留火状态增伤、电弹跳的选择资格。

精英清单22项由资料站中文名称、char标识与本机客户端PixelSprites映射交叉核对。预览优先用char，缺失时才用明确的planta加variant。命中避让名单的路线风险加40（综合评分减120），是有限偏好，不删除候选；保留必经fallback。名单默认空，不影响原路线评分。选中名单后“仅推演”也会读取缺失的正常房间预览，不入场、不战斗、不花资源。

圣所增加健康和魂力门槛判断，使长效磨利不被少量魂力缺口压过；紧急治疗与复活仍优先。磨利队员的长期价值用已装备伤害技能系数、冷却和群攻估计，结合下一战推演；它是策略估值，不是服务端精确收益。

标记来源、标记加深、对标记目标增伤进入近似时序模型，按描述百分比与上限计算。标记持续时间在模型暂用10秒，延长持续时间、完整DOT和元素反应仍未完整复刻；这些候选仍须结合未知效果诊断，不宣称全局最优。新解析和排序通过离线对照验证，本次没有消耗绳索进行额外实战。历史战绩不得作为1.2实战成绩。


## 1.3 策略及假设变化

本节替代前文历史版本中的单盾限制和火雷软回避规则。可继承冻结核心只需一个，缺少时必须优先继承；传说普攻冻结加五次弹跳独立判断升级，不被已有电系弹跳遮蔽。已有核心后允许叠加多个高级开局盾（按可见护盾百分比估值），商店与继承均不再限制一张；同牌最多三份是游戏叠层规则。

普攻点燃与普攻带电按已核对ID及西语、中文、英文效果描述硬过滤，不按整个火/电家族禁用。仅剩禁牌时暂停，不编造跳过接口。纯电伤是否清除冻结尚缺服务端证据，新增可切换假设，默认不清除。客户端组合界面只是读取consumes字段，并非深渊服务端战斗实现；火技能事件不等同燃烧DOT。

配置不再限制人为范围，非正模拟次数关闭抽样并返回未知胜率；无抽样时路线风险仍参加排序。非正间隔不额外等待，非正循环次数不新入场。数值超出模型计算精度时明确暂停，不偷偷截断配置。历史真实战绩不属于1.3验证；本轮只运行隔离回归，不消耗玩家资源。

## 1.3.1 策略和恢复变化

本节替代此前重复护盾高于输出的排序。保留首个可继承冻结核心、传说五次弹跳升级和首张开局盾优先；随后是新增或更快弹跳、减速增伤、异常增伤、首次减速、有效标记、攻击/攻速/双暴等输出。同档比较模拟收益。额外高级盾仍合法，但低于有效输出；纯冰毒防御不再仅因家族额外加分。无标记来源时，标记专用强化不抢输出名额。

契约避让只过滤自动签约，不改变或假装精确模拟契约的服务端战斗效果。costra 与 escurridizos ID 及短描述来自本机历史回执，分别表示前8次受击无效和敌人15%闪避。两开关默认开启，已签约不会撤销。

复活先选择一个倒地英雄，不运行无关战斗预览或战斗模拟；成功后核验同一深渊、指定英雄已站起且眼泪恰好减少1，再决定下一个英雄。桥接清空预览，目标分配以run.heroes最新存活队员为准。截图场景以隔离样例验证，不宣称本轮消耗真实眼泪实测。

超时默认最多恢复两次。已发出但结果未知的操作只查询sima.get，再按操作类型正向核验：战斗房间新增完成标记、指定英雄站起且眼泪减少1、当前节点签约完成、商品新增购买记录等。没有状态变化不能证明操作失败，因此不会盲目重复消费；终局退出深渊或无法明确匹配的状态仍暂停。明确未发送和只读预览允许重试。恢复结果单独标记，不冒充已收到原始成功回执，也不伪造缺失的战斗结果或胜率。截图13秒间隔与历史客户端12秒请求超时一致，只能支持超时判断，不能从截图确定网络故障根因。

1.3.1新增：Boss房间与普通、精英战斗共用“自动缔约的前几层”设置；默认7对应P0～P6，超出不签，仍需冻结核心并遵守两种契约避让。新增“前X层不选护盾牌”，默认开启、7层，遗物、徽章、商店及继承统一执行。前7层不补首盾，P7起或关闭开关后恢复正常首盾优先；已持有的盾不会移除。如果强制选牌全部是护盾或禁牌，会明确暂停，可手动处理或关闭护盾避让后继续，不虚构跳过接口。


## 1.3.2 选牌与章节复核（替代历史硬禁和首盾排序）

- 普攻点燃默认允许、普攻带电默认禁止，独立开关仅控制施加状态的普攻牌；已知ID及中英西语描述参与识别，对燃烧目标增伤不误认成施加点燃，其他火电牌不按家族禁用。
- 第一优先取得一份并继承普攻冻结，不再额外追冻结升级。冻结加全体弹跳的混合牌只有提供新增/更快弹跳时才获得弹跳权重。尚无冻结时冰系作兜底但不压过弹跳；继承后冰减速硬性跳过，非弹跳冰伤软避让，纯冰盾可少量补充并遵守前X层护盾限制。强制菜单只有冰伤可兜底，只有冰减速则明确暂停，不编造跳过接口。
- 冻结继承后依次比较：首次或更快全体弹跳、尚未持有的独立普攻效果各一份、引爆器一份（允许点燃时加权）、火增伤、其他增伤、普通输出。引爆器与独立效果已持有则不重复拿/继承；同牌数值每份减350，同档或更慢弹跳另减175。这些是策略权重，不是游戏伤害或抽取概率，三份上限不变。
- 历史回执确认部分连续选牌是遗物后触发本章徽章：后者加入blasones，不加入reliquias，也不出现在guardaPendiente.cartas；跨章后清空。不将徽章冒充冻结继承，不承诺改变游戏规则来保留它。
- llegada.reliquias给出入章时的遗物数量，使用当前遗物前缀还原旧继承；旧快照缺少该字段时才按候选外旧牌与llevas回退。入章元数据优先，不因本章卡缺席继承菜单就误认为它早已继承。
- 继承回执核验后立即使用新章实际保留的牌进行本地普通房间先验推演，深度使用当前值，不再加一、不重放旧Boss。章节复核单独记入chapterReviews及报告，不计入已执行游戏操作或实战成绩。关闭抽样时胜率未知。
- 引爆器的普攻消耗在模型元素反应后处理，技能不误触发普攻引爆；它仍是近似时序，不代表服务端实现。玩家反馈冰减速可能影响冻结触发尚无足够证据，通过自动选牌硬性避让，不伪造触发率或服务端结论。

### 1.3.2 实际策略权重

先执行硬性过滤，再按策略权重降序；**只有权重相同才比较本地模拟分数**。权重不是游戏伤害百分比，也不是抽卡概率。下表为默认“冻结与异常构筑优先”开启、已继承冻结、无重复扣分时的数值；首个冻结与前期兜底另列。

| 条件/效果 | 基础权重 | 说明 |
|---|---:|---|
| 首个普攻冻结 | 2000 | 尚缺可继承冻结时先拿并继承一份 |
| 首个冻结同时附带5次全体弹跳 | 2200 | 只在缺冻结时优先选更完整的首份，不是重复冻结升级奖励 |
| 新增/更快全体弹跳 | 1950 − min(50, 触发次数) | 5次1945、16次1934、20次1930；比已持有周期更短才获此档 |
| 尚未持有的普攻独立效果 | 1900 | 冻结继承后，点燃/允许的带电/中毒/标记/嘲讽等各一份；遵守独立开关 |
| 首份引爆器 | 1850 | 冻结已继承且允许普攻点燃；已有则硬跳过，不继承第二份 |
| 火系增伤 | 1800 | 火系反应增伤、状态增伤、攻击/攻速/双暴等输出 |
| 其他条件/反应增伤 | 1450 | 异常增伤、非多余冰伤等 |
| 标记来源（未进入1900档时） | 1400 | 作为补充来源，不与独立效果重复计分 |
| 有来源的标记加深/对标记增伤 | 1390 | 无来源时不会拿到这档奖励 |
| 普通攻击/攻速/暴击/暴伤等 | 1350 | 按卡牌实际描述解析 |
| 首份开局护盾 | 1000 | 已有冻结，且过了前X层或关闭护盾避让 |
| 首个其他减速来源 | 700 | 继承冻结后的冰减速已在硬过滤排除 |
| 额外开局盾≥20% / 较小盾 | 300 / 150 | 低于有效输出，仍受前X层限制 |
| 其他防御/补充 | 100 | 不设置防御高权重，不保证固定张数 |
| 尚无冻结核心时的冰系兜底 | 1875 | 冻结和新增弹跳之后、普通增伤之前；本章取得冻结后不继续靠该加分堆冰 |
| 继承冻结后多余冰伤兜底 | −500 | 有其他合法牌就不选，商店直接略过；强制只剩它时可选择 |

以上是分支匹配，**不是各项相加**。多效果牌按最先命中的档位计分，另减重复处罚。已有冻结时混合冻结+弹跳牌可为了新增或更快弹跳选择，但不因为冻结效果重复而额外加分。

- 同ID每已有一份，扣350；同档或更慢弹跳再扣175。若该混合牌新增了未持有独立普攻效果，不因附带旧弹跳扣175，避免漏补新状态。同ID扣350仍保留。
- 例：已拿一份熔炉类火数值牌，下一份从1800降至1450；另有不同火增伤1800时优先后者。已有一份20次火弹跳且已有更快弹跳时，重复20次牌从1800降至1275，不照抄参考截图继续堆同牌。
- 独立普攻重复、已有引爆器、普攻开关禁用项、继承冻结后的冰减速、前X层护盾、三份上限均为硬过滤，内部无效分−10000不是低概率候选。引爆器变体即使附带数值也不继承第二份。其他独立普攻混合牌若带新增/可比较弹跳，仍可按弹跳/数值收益比较，并非为了叠独立状态。
- 默认火开、电关；关闭点燃时引爆器不获1850加分，旧状态消耗回避开启时为−100，否则普通补充100。其他火增伤和电弹跳不按元素家族禁用。
- 关闭构筑偏好后，首个冻结仍优先，硬过滤与冰伤避让仍生效，其余主要比较模拟；重复扣分仍保留。设置中的“冰冻遗物权重”是模拟冻结覆盖偏好，不等同于这里的策略档位。
- 遗物与商店去重基于可保留遗物；徽章基于本章全部效果；继承只对旧继承列表比较。临时徽章不冒充下一章保留效果。每章只新增带走一张，不保证本章所有独立效果都能同时继承，下一章没保留的效果仍可重新争取。

玩家截图仅用作本地构筑参考，未照抄完整牌序或假定所有卡都应叠满。模型合并独立布尔效果、用当前已解析的最快全体弹跳周期近似覆盖，按描述累加可识别数值；并不代表已掌握多个弹跳来源、状态反应或减速对冻结的服务端精确结算。
