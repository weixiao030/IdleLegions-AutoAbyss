## 1.3.5：目标分配与模拟稳定性

## 当前冻结收集策略（覆盖1.3.3冻结只取一份）

冻结未确认继承前，允许优先多拿普攻冻结；本章已经拿到同ID、其他冻结变体或临时冻结徽章，都不因为重复而排除或降权。普通冻结维持2000，冻结附带5次全体弹跳维持2200，高于其他冰牌1950；仍优先冰系，不让火系或非冰弹跳提前抢选。只有下一章回执确认已经继承一份冻结后，才结束收集阶段：纯冻结正常不再重复拿，带新增/更快弹跳或其他有效增益的混合牌按既有权重、重复降权和护盾偏好比较。

多拿只改变选牌偏好，不把冻结布尔效果模拟成多倍伤害或更高触发率，也不伪造具体继承概率。每章仍只新增继承一张，不宣称多拿的冻结会全部带入下一章。实际游戏不可用项不派发，策略候选筛空仍沿用择优兜底，不要求玩家手动处理。

## 当前1.3.3策略（替代下文历史硬过滤与前期1875兜底）

普攻冻结确认继承前，正常候选优先只拿冰系，包含冰减速；本章刚取得冻结或仅有临时徽章，都不提前切换火系。首份冻结优先取得并占用本章新增继承名额。确认继承后依次优先新增/更快全体弹跳、独立普攻各一份、引爆器一份、火增伤、其他输出和少量防御；优先避开冰减速与多余冰伤。按玩家反馈用冰系积累系列倾向，但没有编造服务端抽取概率。

已有燃烧并不代表另一张燃烧牌整张无效：例如截图第三张“烈焰”（br_incendio）还附带伤害+4%，独立燃烧不重复加分，但这部分可识别数值仍可比较。无新增独立效果、无弹跳但有附带数值的重复状态牌额外减600，避免压过更好的新输出；同ID每份另减350。纯重复状态正常避让，引爆器仍优先只留一份。

所有选牌偏好统一支持择优兜底：正常候选为空时，只从游戏实际可选卡中放宽偏好、扣分比较，不因前X层护盾、独立开关、重复状态、仅冰阶段或继承叠层偏好而暂停。前X层护盾改为“优先不选”，默认开启、7层（P0～P6）；实在无合适选择可以拿盾。兜底会显示原避让原因及扣分。游戏标记不可用、缺ID、余额不足、请求失败或回执异常不能靠兜底冒充成功；没有任何游戏可用选项时保留状态保护，不杜撰接口。

本节替代前文历史版本中的单盾限制和火雷软回避规则。可继承冻结核心只需一个，缺少时必须优先继承；传说普攻冻结加五次弹跳独立判断升级，不被已有电系弹跳遮蔽。已有核心后允许叠加多个高级开局盾（按可见护盾百分比估值），商店与继承均不再限制一张；同牌最多三份是游戏叠层规则。

普攻点燃与普攻带电按已核对ID及西语、中文、英文效果描述硬过滤，不按整个火/电家族禁用。1.3.3起仅剩策略避让牌时从游戏实际可用候选择优兜底，不编造跳过接口。纯电伤是否清除冻结尚缺服务端证据，新增可切换假设，1.3.5默认开启清除假设（此前默认不清除）。客户端组合界面只是读取consumes字段，并非深渊服务端战斗实现；火技能事件不等同燃烧DOT。

## 1.3.2 选牌与章节复核（替代历史硬禁和首盾排序）

- 普攻点燃默认允许、普攻带电默认禁止，独立开关仅控制施加状态的普攻牌；已知ID及中英西语描述参与识别，对燃烧目标增伤不误认成施加点燃，其他火电牌不按家族禁用。
- 第一优先取得一份并继承普攻冻结，不再额外追冻结升级。冻结加全体弹跳的混合牌只有提供新增/更快弹跳时才获得弹跳权重。尚无冻结时冰系作兜底但不压过弹跳；继承后冰减速硬性跳过，非弹跳冰伤软避让，纯冰盾可少量补充并遵守前X层护盾限制。强制菜单只有冰伤可兜底，只有冰减速则明确暂停，不编造跳过接口。
- 冻结继承后依次比较：首次或更快全体弹跳、尚未持有的独立普攻效果各一份、引爆器一份（允许点燃时加权）、火增伤、其他增伤、普通输出。引爆器与独立效果已持有则不重复拿/继承；同牌数值每份减350，同档或更慢弹跳另减175。这些是策略权重，不是游戏伤害或抽取概率，三份上限不变。
- 历史回执确认部分连续选牌是遗物后触发本章徽章：后者加入blasones，不加入reliquias，也不出现在guardaPendiente.cartas；跨章后清空。不将徽章冒充冻结继承，不承诺改变游戏规则来保留它。
- llegada.reliquias给出入章时的遗物数量，使用当前遗物前缀还原旧继承；旧快照缺少该字段时才按候选外旧牌与llevas回退。入章元数据优先，不因本章卡缺席继承菜单就误认为它早已继承。
- 继承回执核验后立即使用新章实际保留的牌进行本地普通房间先验推演，深度使用当前值，不再加一、不重放旧Boss。章节复核单独记入chapterReviews及报告，不计入已执行游戏操作或实战成绩。关闭抽样时胜率未知。
- 引爆器的普攻消耗在模型元素反应后处理，技能不误触发普攻引爆；它仍是近似时序，不代表服务端实现。玩家反馈冰减速可能影响冻结触发尚无足够证据，通过自动选牌硬性避让，不伪造触发率或服务端结论。

### 1.3.2 实际策略权重

先执行硬性过滤，再按策略权重降序；**只有权重相同才比较本地模拟分数**。权重不是游戏伤害百分比，也不是抽卡概率。下表为默认“冻结与异常构筑优先”开启、已继承冻结、无重复扣分时的数值；首个冻结与前期兜底另列。

| 条件/效果 | 基础权重 | 说明 |
|---|---:|---|
| 首个普攻冻结 | 2000 | 尚缺可继承冻结时先拿并继承一份 |
| 首个冻结同时附带5次全体弹跳 | 2200 | 只在缺冻结时优先选更完整的首份，不是重复冻结升级奖励 |

| 尚未持有的普攻独立效果 | 1900 | 冻结继承后，点燃/允许的带电/中毒/标记/嘲讽等各一份；遵守独立开关 |
| 首份引爆器 | 1850 | 冻结已继承且允许普攻点燃；已有则硬跳过，不继承第二份 |

| 其他条件/反应增伤 | 1450 | 异常增伤、非多余冰伤等 |
| 标记来源（未进入1900档时） | 1400 | 作为补充来源，不与独立效果重复计分 |
| 有来源的标记加深/对标记增伤 | 1390 | 无来源时不会拿到这档奖励 |

以上是分支匹配，**不是各项相加**。多效果牌按最先命中的档位计分，另减重复处罚。已有冻结时混合冻结+弹跳牌可为了新增或更快弹跳选择，但不因为冻结效果重复而额外加分。

- 同ID每已有一份，扣350；同档或更慢弹跳再扣175。若该混合牌新增了未持有独立普攻效果，不因附带旧弹跳扣175，避免漏补新状态。同ID扣350仍保留。
- 例：已拿一份熔炉类火数值牌，下一份从1800降至1450；另有不同火增伤1800时优先后者。已有一份20次火弹跳且已有更快弹跳时，重复20次牌从1800降至1275，不照抄参考截图继续堆同牌。
- 独立普攻重复、已有引爆器、普攻开关禁用项、继承冻结后的冰减速、前X层护盾、三份上限均为硬过滤，内部无效分−10000不是低概率候选。引爆器变体即使附带数值也不继承第二份。其他独立普攻混合牌若带新增/可比较弹跳，仍可按弹跳/数值收益比较，并非为了叠独立状态。
- 默认火开、电关；关闭点燃时引爆器不获1850加分，旧状态消耗回避开启时为−100，否则普通补充100。其他火增伤和电弹跳不按元素家族禁用。
- 关闭构筑偏好后，首个冻结仍优先，硬过滤与冰伤避让仍生效，其余主要比较模拟；重复扣分仍保留。设置中的“冰冻遗物权重”是模拟冻结覆盖偏好，不等同于这里的策略档位。
- 遗物与商店去重基于可保留遗物；徽章基于本章全部效果；继承只对旧继承列表比较。临时徽章不冒充下一章保留效果。每章只新增带走一张，不保证本章所有独立效果都能同时继承，下一章没保留的效果仍可重新争取。

玩家截图仅用作本地构筑参考，未照抄完整牌序或假定所有卡都应叠满。模型合并独立布尔效果、用当前已解析的最快全体弹跳周期近似覆盖，按描述累加可识别数值；并不代表已掌握多个弹跳来源、状态反应或减速对冻结的服务端精确结算。
