# 1.3 模型说明

1.0 沿用 0.4.3 的模型与策略，以下证据及边界说明来自 0.4.3，未将历史验证视为 1.0 新增实战。

## 0.4.3 模型证据与边界

- 原游戏未修改；使用客户端现有正常深渊操作及战斗回放事件。
- 已读客户端 sima_panel.gd 的请求流程和 battle_view.gd 的 `_teatro_srv` / `_srv_con_puerta`。这些来自 2026-11-03 提取的版本，只作架构线索；当前运行的结果由真实事件核对。
- 深渊结算在服务端；没有取得服务端引擎或全部敌人属性，不能声称精确复刻。
- 真实事件字段：t、side、src、dst、dmg、hpPct、crit、skill、reaction、est、sest、rel。dmg<0 为治疗。冻结标记 congelado；火消耗冻结的 reaction 为 vaporizacion。
- 核心 ID 已实测出现 es_carambano、es2_carambano；es_glaciar 描述也包含普攻冻结。普通寒冷牌不再硬排在其他系列前。
- 当前卡牌效果从玩家可见 desc 解析：攻速、生命、防御、条件增伤、护盾、吸血、击杀治疗、减速、群攻周期和普攻状态。未解析部分列在候选诊断里，不伪造效果。
- 冻结是普攻触发，不存在无核心随机冻结。直接火技能触发汽化按历史事件近似；燃烧DOT不据此推断为清除冻结。1.3起纯电伤的清除行为为可切换的待确认假设，默认不清除。
- 敌人 HP 从累计伤害与 hpPct 回推；输出从事件拟合。全程被冻、没有出手的敌人是删失样本，不当成零攻击力。冰冻间隙的短暂爆发不再直接外推为全程持续 DPS。
- 默认冻结时长 1 秒是未识别服务端参数的模型假设，可调并进行随机敏感性抽样；非游戏官方常量。
- 敌人层间/房间缩放、施法准备、伤害减免、DOT、光暗反应和保护技能尚非完整引擎；采用经验估计与宽泛不确定性。技能描述系数及冷却参与时序，部分行为无法确认。
- 37 场按时间先预测后学习：开发初版 Brier 0.2243，修正短爆发外推后 0.0711。此批已用于调参，是开发诊断，不是独立留出验证。当前角色技能近似历史槽位、目标由首击反推，是额外限制。
- 新的真实下潜结果作为后续验证，报告保留误差和资源收益，不声称反事实全局最优。
- 奖励指 botin.nucleos（核心资源）及 botin.esquirlas（碎屑），不把奥波币或遗物数量替代资源收益。掉落率未知，路线权重仅表达偏好。
- 最终开发审计 43 个评估样本平均 Brier 0.059025，仍是开发数据。稳定模型 D 的后续真实记录为 26 场、25 胜 1 负，Brier 0.049345；整轮含旧版阶段共 47 场、46 胜 1 负，P9 战败，核心净增 2、碎屑净增 3，撤离 0。
- 实测结束后追加报告战斗标识去重、迷雾转战斗空预览刷新；最终构建 40 项自测通过。该缓存修复未重跑一轮全程实战，不宣称它能改变 P9 的失败结果。

0.4.1 新增低血防御语句别名，继承改用下一层普通房间先验，排除刚击败的首领。0.4.2 新增商店不购买基线及先买后走、小缺口补给、碎屑服务、圣所磨利和 Rencor 条件增伤。消费额从确认前后余额计算。47 项自测通过；本次 5 把结果及版本范围以实测报告为准。前文旧版开发集结果保留作历史证据。

0.4.3：构筑排序按最新要求固定为缺失可继承冻结核心 → 暴击/暴伤 → 伤害与弹跳；缺可继承核心时积累寒冷，本层徽章不代替可继承遗物。排序优先级与战斗胜率分开，不把系列牌更多带来的概率变化编成具体数值。

继承输入来自 guardaPendiente.cartas、候选的 llevas、run.reliquias。候选清单只描述本层可新增的牌，不能用它替代全部已继承清单。候选外旧牌及候选中 llevas 份旧牌保留；再新增所选一张（每种最多三张）。下一深度回执逐张核验，不把 blasones 或 buffs 当成跨层遗物。客户端反编译的 _eleccion_pendiente / _reliquias_mesa / _guarda_mesa 提供历史参考；当前游戏真实回执才用于确认实际行为。

循环控制新增次数/用尽绳索模式；隔离回执集成测试只验证状态机，不计入真实战斗统计。0.4.3 的真实两次循环和继承核验结果另见本版实测报告，前文历史版本数据不混入本版成绩。


## 1.2 策略与模型变化

构筑顺序更新为缺失可继承冻结核心、传说冻结五次弹跳升级、一个可继承开局护盾、减速来源、减速增伤、异常增伤和弹跳；冰毒补充优于暗影标记与双暴。旧版双暴优先仅是历史记录。购买不重复追第二张开局盾；本层徽章仍不能代替下层可保留的核心或护盾。传说毒弹跳的复数描述、10% 更慢别名、晨昏护盾短句均加入解析。火雷回避只针对实际消耗状态的普攻，保留火状态增伤、电弹跳的选择资格。

精英清单22项由资料站中文名称、char标识与本机客户端PixelSprites映射交叉核对。预览优先用char，缺失时才用明确的planta加variant。命中避让名单的路线风险加40（综合评分减120），是有限偏好，不删除候选；保留必经fallback。名单默认空，不影响原路线评分。选中名单后“仅推演”也会读取缺失的正常房间预览，不入场、不战斗、不花资源。

圣所增加健康和魂力门槛判断，使长效磨利不被少量魂力缺口压过；紧急治疗与复活仍优先。磨利队员的长期价值用已装备伤害技能系数、冷却和群攻估计，结合下一战推演；它是策略估值，不是服务端精确收益。

标记来源、标记加深、对标记目标增伤进入近似时序模型，按描述百分比与上限计算。标记持续时间在模型暂用10秒，延长持续时间、完整DOT和元素反应仍未完整复刻；这些候选仍须结合未知效果诊断，不宣称全局最优。新解析和排序通过离线对照验证，本次没有消耗绳索进行额外实战。历史战绩不得作为1.2实战成绩。


## 1.3 策略及假设变化

本节替代前文历史版本中的单盾限制和火雷软回避规则。可继承冻结核心只需一个，缺少时必须优先继承；传说普攻冻结加五次弹跳独立判断升级，不被已有电系弹跳遮蔽。已有核心后允许叠加多个高级开局盾（按可见护盾百分比估值），商店与继承均不再限制一张；同牌最多三份是游戏叠层规则。

普攻点燃与普攻带电按已核对ID及西语、中文、英文效果描述硬过滤，不按整个火/电家族禁用。仅剩禁牌时暂停，不编造跳过接口。纯电伤是否清除冻结尚缺服务端证据，新增可切换假设，默认不清除。客户端组合界面只是读取consumes字段，并非深渊服务端战斗实现；火技能事件不等同燃烧DOT。

配置不再限制人为范围，非正模拟次数关闭抽样并返回未知胜率；无抽样时路线风险仍参加排序。非正间隔不额外等待，非正循环次数不新入场。数值超出模型计算精度时明确暂停，不偷偷截断配置。历史真实战绩不属于1.3验证；本轮只运行隔离回归，不消耗玩家资源。
