# 1.3.1 发布验证

日期：2026-11-09；Windows x64。本轮使用隔离配置、离线样例和模拟桥接，不启动真实游戏、不消费绳索或眼泪，不修改游戏本体。

## 功能

- Boss房间按现有PactFloors层数先缔约，默认P0～P6；P7不签，已签不重复，costra/escurridizos仍避让。
- 新增默认开启的“前X层不选护盾牌”，默认7层（P0～P6）；四个选牌入口统一执行。边界后或关闭开关恢复首盾优先，已有盾保留；强制选牌只剩护盾或禁牌时明确暂停，不擅自违反配置。

- costra 前8次受击免疫、escurridizos 15%闪避契约新增独立避让开关，默认开启，自动保存。已签约不撤销，避让后房间照常打。
- 先核心与首盾，随后优先新增/更快弹跳、异常/减速增伤和攻击双暴，额外高级盾与冰毒纯防御不再抢输出名额；禁普攻点燃/带电及游戏叠层上限继续生效。
- 先逐个复活，再读取预览、继续前进；复活核验指定英雄站起及眼泪减少1，成功清空预览，使用最新存活成员分配目标。
- 超时自动恢复默认开启，最多两次；只读请求及确认未发出的操作可重发，未知结果先查游戏状态，正向核验已完成则继续。两次仍不能核验时保留暂停，不重复消费。终局无可匹配run时保持暂停。日志和报告注明恢复来源。

## 验证

后端177项自测通过，覆盖原回归和三个开关默认/旧配置迁移/保存重载、两种契约独立避让及其他契约继续、遗物/徽章/继承/商店的输出排序、两倒地两眼泪连续复活及正常前进、旧预览不遗漏复活英雄、丢失回执后的复活/战斗状态核验、两次恢复上限、未发出与只读请求重试、关闭恢复即暂停及不同深渊不误判；另覆盖Boss签约层数/避让、护盾开关和X层边界、四入口过滤及只有盾时安全暂停。

浏览器隔离验证29项通过，覆盖四个开关与层数默认值、自动保存、刷新恢复、导入导出、运行中前后端锁定，以及1440/390像素浅色、390像素深色布局无横向溢出；没有未处理的浏览器异常。桥接GDScript语法解析通过。Windows x64自包含EXE已构建，发布打包脚本逐文件核对SHA-256与ZIP完整性；校验值随发行包提供，远程CI结果以发布记录为准。没有将历史实战成绩计入1.3.1，也没有声称复现截图网络故障。
