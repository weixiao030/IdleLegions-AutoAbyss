# v1.3.6 发布验证

日期：2026-11-10。Windows x64 自包含发行，桥接版本0.3.3。

## 变更与验证范围

- 三策略切换、自动保存与运行锁。策略二对比真实v1.3.1标签，独立保留原版效果、选牌、商店、目标组合和模拟器。
- ICE七系各8张遗物，徽章不计；冻结继承、4/5/6次弹跳、8/10次必暴优先。用户六图按效果识别，涵盖中西文、全部换位、首选缺席/不可用及四个选牌入口，共1136项场景检查。
- 正式EXE默认隔离自测1687项通过；另加既有战斗回执复盘为1688项。历史回执复盘不代表新版策略已经实战通关。
- Release构建0警告0错误；前端构建成功。Vite仍有Radix use-client与包体大小提示，不影响构建。
- 网页版本取自package.json，与EXE、打包脚本和CI统一为1.3.6。控制区使用运行方式选择和一个主操作，暂停可继续原计划；策略及次数修改在运行期间锁定。
- 网页62项检查通过，使用隔离模拟API验证单次/计次/绳索用完请求、暂停继续、无效次数、策略保存与刷新、报告筛选、参数折叠、维护操作、深浅色与390px窄屏。未向真实游戏派发命令。
- 角色输出占比、DPS、结算生命损失、互斥来源、卡牌直接触发以及资源差分按回执展示；缺字段保持未确认。重启只恢复展示，不恢复自动执行。
- 桥接0.3.3在同版本Godot引擎、独立PCK和虚构结算夹具中通过9项检查。装备从独立结算收据或明确标注的背包新增取得；邮寄/待领只有数量时不猜名称。

## 升级与边界

先退出旧工具。需要新增装备证据时，正常关闭游戏，在新版“连接设置”安装/更新桥接0.3.3，再启动游戏登录。仅替换EXE不会更新已加载脚本；旧桥接兼容六图选牌和基础战报。不要同时运行两个控制器。

保留玩家明确设置；新字段采用默认值。导入整套新预设前先导出参数。回滚时退出新版，恢复桥接配置/脚本备份并使用旧EXE。

未进行新版真实下井、资源消费或真实神话掉落实测。预测为本地近似，胜负和物品以游戏实际结算为准。

## 发行完整性

Windows CI对发行提交重新构建、运行默认自测并打包。ZIP仅包含EXE、白名单说明文档、许可证和逐文件SHA-256清单；ZIP外附.zip.sha256与SHA256SUMS.txt。本地账号快照、反编译游戏源码及测试输出不发布。
