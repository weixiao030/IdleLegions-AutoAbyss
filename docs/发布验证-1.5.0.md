## 可复现入口

- dotnet build app/FrostAbyss.csproj --no-restore
- dotnet app/bin/Debug/net8.0-windows/win-x64/IdleLegions自动下井.dll --self-test --self-test-dir output/recheck
- dotnet app/bin/Debug/net8.0-windows/win-x64/IdleLegions自动下井.dll --validate-model --audit-trials 32 --audit-max 3850 --audit-output output/audit-recheck.json
- 在ui目录执行npm ci、npm test、npm run build。
- ./build.ps1构建，python tools/package_release.py生成白名单完整包并验证ZIP条目及SHA-256。发行程序的--self-test请使用Start-Process -Wait，以等待WinExe结束。

## 升级与回滚

从托盘退出旧工具，解压1.5.0完整包到新目录再运行；本机显式配置和历史记录沿用，不需要为了升级重新入场。策略四缺比较模式时采用收益比较；旧无模式的专用导出文件仍按系列排序导入。仅在界面提示桥接过旧时按原教程更新桥接。

回滚时先退出新版，再运行保留的旧版EXE；保留learning-v1数据目录，无需删除用户战报。源码改动前备份在output/goal-backup-20261112-000250、output/continuation-backup-20261112及output/finalization-backup-20261112。打包白名单不包含用户历史、令牌、配置或测试语料。
