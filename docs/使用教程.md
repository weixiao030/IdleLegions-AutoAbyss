# IdleLegions自动下井安装与使用教程

版本 1.4.1　更新日期 2026年11月11日

本教程带你完成首次安装、桥接连接、运行策略选择和自动下潜。请按顺序完成前两页；看到“游戏已连接”后，再开始下潜。软件适用于64位Windows 10或11、Steam版Idle Legions，账号需要已解锁深渊。

## 第一步 解压并打开工具

1. 下载完整包 IdleLegions-AutoAbyss-v1.4.1-win-x64.zip，右键选择“全部解压”，放入一个固定文件夹。
2. 如果已有旧工具，从系统托盘找到本工具图标，选择“退出”。关闭浏览器页签不等于退出程序。
3. 双击解压目录内“IdleLegions自动下井.exe”。浏览器自动打开中文控制台，右上角应显示 v1.4.1。

发行包已包含所需运行环境，不用安装 Node.js、Python 或 .NET。请保留完整目录，不在ZIP内直接双击运行。

## 第二步 在连接设置指定游戏

1. 正常关闭 Idle Legions 游戏。安装桥接时保持游戏关闭，避免游戏继续使用旧脚本。
2. 在工具网页左侧点击“连接设置”。这里负责游戏路径、桥接安装以及启动游戏。
3. 如果没有自动找到游戏，在游戏路径框填写 client.exe 的完整路径，等待自动保存提示完成。

找路径的方法：在Steam库中右键 Idle Legions，选择“管理 → 浏览本地文件”。复制地址栏目录，确认其中有 client.exe，再在工具内填写完整路径。例如 D:\SteamLibrary\steamapps\common\Idle Legions\client.exe；请按本机实际目录填写，不能只填游戏文件夹。

## 第三步 安装桥接并登录游戏

1. 仍在“连接设置”，确认游戏已关闭，然后点击“安装 / 更新桥接”。
2. 等待页面或日志提示桥接安装成功、配置已备份。程序会添加自己的自动加载项，不需要手动复制 bridge 文件夹，也不要手工修改游戏配置。
3. 点击“启动游戏”，在游戏内正常完成登录。
4. 回到工具控制台，等待右上角显示“游戏已连接”。只有显示已连接才进入下一步。

工具版本为1.4.1，自带桥接为0.3.6，两者版本号不同是正常的。若显示旧桥接或未知版本提示，先正常关闭游戏，再重复“安装 / 更新桥接 → 启动游戏 → 登录”。仅换新版EXE而不重启游戏，不会更新已经加载的桥接。

## 第四步 检查站位和保存状态

1. 打开“策略参数”，在“职业与站位”确认四个职业都是自己已拥有的职业。
2. 前两位为前排，后两位为后排。默认依次为狂战士、法师、弓箭手、圣骑士；选择已上阵职业会自动交换位置。
3. 修改后等待自动保存完成，无需寻找保存按钮。已在井内的队伍不会因修改立即更换，新站位下次入场生效。

初次使用可先保留默认2000次推演与1000毫秒操作间隔。导入“默认参数.json”会覆盖相应个人设置，已有方案请先导出备份。

## 第五步 选择策略并开始自动下潜

1. 打开“下潜控制”，在“下潜策略”选择策略一至策略四。想使用自己的选牌顺序，应明确选择“策略四”。
2. 在“运行方式”选择“单次下潜”“循环指定次数”或“循环到绳索用完”。次数模式填写目标次数，并检查策略参数中的保留绳索。
3. 如需先看建议，点击“仅推演，不执行”；它只查看候选，不进行游戏操作。
4. 确认保存完成且显示“游戏已连接”，点击“开始下潜”。出现“正在自动下潜”后，程序会处理路线、战斗、选牌、商店及继承。

已有深渊会优先继续，不需要为测试重新入场。默认不主动撤离；一轮到最深通关或战败后结束，再按选定循环计划决定是否新入场。循环到绳索用完会使用最后一根绳索，不保留2根。

## 自动流程遇到没有冰冻时

策略四会先抓寒冰和普攻冰冻。继承菜单没有冰冻，就自动择优继承其他合法遗物，进入下一层继续寻找，不因此跳过或停住。下一章真实回执确认冰冻遗物已继承后，才使用你的自定义选牌。

本章刚取得冰冻或临时徽章提供冰冻，仍不等于已继承。控制页的“冰冻构筑”会说明当前处于寻找、等待继承还是自定义阶段。

需要修改参数时，点击“暂停下潜”并等待当前操作回执完成。重新开始时选择“继续当前计划”可以沿用原循环安排；关闭网页不会停止下潜，从托盘仍可重新打开控制台。

## 第六步 设置策略四自定义选牌

1. 自动下潜未运行时，打开左侧“自定义选牌”。先查看卡图、中文名称和效果，按自己的构筑目标设置。
2. 长按系列左侧手柄约三分之一秒，拖动到目标位置松开；越靠前越优先。细分类同样排序，也可用上下移按钮。
3. 再调整同类单卡优先级，1最高、2其次。比较顺序是系列、细分类、单卡，单卡写1不会跨到其他系列前面。
4. 按需设置目标张数、软避让和拉黑。目标张数0表示不限；强制菜单会按正常、软避让、拉黑末位兜底，商店不会为兜底乱花钱。
5. 等待自动保存，再回到“下潜控制”选择策略四并开始。修改不会影响策略一至三，也不会修改1.3.1原版策略。

如果希望雷电系列优先于烈焰，把雷电拖到烈焰前面；然后在雷电内部安排细分类，最后修改某张卡的数字。默认值已提供1.3.1评分的静态参考，可以在此基础上调整。

## 保存和分享选牌方案

点击“导出选牌”下载专用JSON。换电脑或恢复方案时点击“导入选牌”，选中该文件，确认保存成功。它只修改策略四选牌，不切换策略，不覆盖站位和模拟次数。错误文件会给出原因并保留原设置。

运行中可以查看图鉴和导出，不能编辑或导入。所有配置折叠区默认展开，不需要逐个点开。

## 第七步 查看结果与处理常见问题

打开“运行报告”查看轮次、深度、角色伤害、卡牌和资源。资源总获取每轮结束统计一次，核心含到账与邮寄，碎屑来自结算收据；深度筛选不拆分整轮，奥波币不计作结算奖励。展开角色，再展开技能或效果，可看到详细构成；网页显示万、亿，导出保留原始数值。新战报的战前构筑来自实际记录，旧记录缺失时不会套用当前装备。

| 遇到的问题 | 应该检查什么 |
|---|---|
| 不能开始下潜 | 是否已连接游戏、参数是否有效、是否仍在保存 |
| 始终等待连接 | 先到连接设置检查client.exe路径，再关闭游戏安装桥接，重启登录 |
| 旧版或未知桥接提示 | 游戏关闭后点击安装或更新桥接，再启动游戏 |
| 策略四没有按自定义选 | 当前是否选中策略四，冰冻是否已经由下一章确认继承 |
| 运行中不能改配置 | 先暂停并等待当前操作完成，再修改 |
| 无冰冻继承候选 | 策略四会自动选择过渡遗物，下层继续寻找，无需手动跳过 |
| 网络或回执不明而暂停 | 查看日志和游戏实际状态，避免手动重复消费；确认后继续计划 |

## 升级与退出

升级时先从托盘退出旧工具，将新完整包解压到新目录，再运行新版EXE；本机参数与历史记录会沿用。若提示桥接升级，按第二页步骤正常关闭游戏再安装。

停止本次自动操作请用“暂停下潜”；退出程序请从系统托盘选择“退出”。退出不关闭游戏。要卸载桥接，先停止流程并关闭游戏，再在“连接设置”点击“卸载桥接”。

更多参数解释和数据路径见《使用说明.docx》。本地预测不保证真实胜率，实际胜负、奖励与消费以游戏结算为准。
